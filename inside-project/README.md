# پروژه‌های داخلی

هر پروژهٔ داخلی در پوشهٔ خود یک `inside-project.json` دارد؛ صفحهٔ Performance سناریوها را از این فایل می‌شناسد. برای افزودن پروژه می‌توانید از [manifest مصرف‌کننده](./consumer/inside-project.json) الگو بگیرید. شناسه و پورت باید یکتا باشند و مسیر پیش‌نمایش باید به شکل `/internal-projects/<id>/` باشد.

در `package.json` ریشه، تنظیم `internalProjects` مشخص می‌کند کدام پروژه‌ها همراه `npm run dev` اجرا شوند. برای نمونه، `"consumer": true` آن را فعال و `false` غیرفعال می‌کند. پروژهٔ جدید تا زمانی که با مقدار `true` در این تنظیم ثبت نشود، خودکار اجرا نمی‌شود. هر پروژه باید در `package.json` خودش فرمان `dev` داشته باشد. پس از تغییر تنظیمات یا manifest، فرمان توسعه را دوباره اجرا کنید.

هر صفحهٔ سناریو باید meta با نام `internal-project` و مقدار `<project-id>:<scenario-id>` داشته باشد. همچنین باید meta با نام `internal-project-ready` را پس از آماده شدن با مقدار `ready` تنظیم کند. اتصال proxy مربوط به محیط توسعه است. جزئیات در [راهنمای مصرف‌کننده](./consumer/README.md) آمده است.
