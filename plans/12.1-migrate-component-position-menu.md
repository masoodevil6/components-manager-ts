## ۰. اصول قابل‌نگهداری و توسعه‌پذیری توسط انسان (الگوی componentButton)

این پلن از الگوهای `componentButton` برای اطمینان از قابل‌نگهداری و توسعه‌پذیری توسط انسان پیروی می‌کند:

### ۰.۱ ساختار فایل‌ها — JSDoc و Section Grouping

| الگو | توضیح | مثال از componentButton |
|:---|:---|:---|
| **JSDoc روی کلاس** | هر کلاس JSDoc با توضیح معماری، Plan reference، و behavior | `ComponentButton` JSDoc شامل Composition architecture + Plan 9.1.1 behavior |
| **JSDoc روی فیلدها** | هر فیلد `protected` / `private` JSDoc دارد | `_HOVER_STATE` — "معادل el.hover قدیمی" |
| **JSDoc روی متدها** | هر متد `protected` / `private` JSDoc دارد | `renderButton`, `renderButtonTitle`, `renderButtonIcon` |
| **Section grouping در Props** | `/// --- Group Name ---` برای دسته‌بندی propها | `/// --- موجود (حفظ) ---` در Props.ts |
| **JSDoc روی enumها** | هر enum JSDoc با توضیح کاربرد | `ButtonSemantic` — "نوع معنایی دکمه" |
| **JSDoc روی type exports** | هر type export JSDoc با usage example | `MethodsConfigType` با مثال `UiCategory.UI.Simples.Button(...)` |
| **`satisfies` keyword** | type safety بدون widening | `satisfies CoreComponents.ComponentProps` |

### ۰.۲ الگوی Render Methods — `protected` برای توسعه‌پذیری

```typescript
// ✅ الگوی componentButton — protected (قابل override توسط فرزند)
protected renderFormFloatMenu(...): CoreReactive.App { ... }

// ❌ anti-pattern — private (غیرقابل توسعه)
private renderFormFloatMenu(...): CoreReactive.App { ... }
```

هر render method:
1. `protected` است (فرزند می‌تواند override کند)
2. ابتدا `const bind = this._COMPONENT_PROPS_BIND;` — دسترسی به prop bindings
3. سپس `const prop_xxx = data?.["prop_xxx"] ?? bind.prop_xxx;` — resolution با fallback
4. در نهایت `CoreReactive.App.section/button/part(...)` — ساخت ReactiveElement

### ۰.۳ الگوی Style Getters — `private` و کوچک

هر style getter:
1. `private` است (implementation detail)
2. فقط یک style را مدیریت می‌کند (single responsibility)
3. `CoreObservable.App.computed(...)` برمی‌گرداند
4. ورودی‌هایش prop bindings هستند (نه مقدار خام)
5. `this.getScope()` برای scope binding

```typescript
// ✅ الگوی componentButton — هر getter یک style
private getStyleBodyContentHeight(prop_menuBodyHeight) {
    return CoreObservable.App.computed(
        (menuBodyHeight, sizeName) => {
            return UtilStyle.Css_SizeCalc(
                menuBodyHeight, "-", UtilStyle.Css_BorderWidth(sizeName),
            );
        },
        [prop_menuBodyHeight, CoreConfig.Settings.SizeName.observable()],
        this.getScope(),
    );
}
```

### ۰.۴ الگوی Step — Factory Function (نه ثابت)

```typescript
// ✅ الگوی componentButton — factory function

// ❌ anti-pattern — ثابت (همه instance‌ها step مشترک دارند)

## ۱. وضعیت فعلی

`ComponentPositionMenu` در `last/tools/components/Positions/ComponentPositionMenu.ts` (959 خط) یک کامپوننت legacy است که از `ComponentBase` ارث‌بری می‌کند و الگوی قدیمی `GOG_*` / `defineComponentPatterns` / `defineComponentSchema` / `defineComponentMethods` را استفاده می‌کند.

### ۱.۱ ساختار فعلی

| بخش | وضعیت | توضیح |
|:---|:---|:---|
| Props | ❌ legacy | `ComponentPositionMenuProps` با `GOG_ComponentBasicProps_*` + ۱۴ prop اختصاصی به‌صورت string constants |
| Configs | ❌ legacy | `ComponentPositionMenuConfigs` با `GOG_SetValue<T>` — نوع و default در یکجا |
| Types | ❌ legacy | `GOG_ExtractNameValue` / `GOG_ExtractName` — استخراج نوع قدیمی |
| Base class | ❌ legacy | `ComponentPositionMenuBase extends ComponentBase<...>` — الگوی قدیمی |
| Concrete class | ❌ legacy | `ComponentPositionMenu extends ComponentPositionMenuBase` — constructor قدیمی |
| Schema | ❌ legacy | `defineComponentSchema` با `this._COMPONENT_PATTERN[...]` — ۷ schema part |
| Methods | ❌ legacy | `defineComponentMethods` با runtime name keys — ۳ method |
| Templates | ❌ legacy | `defineComponentTemplate` — مفهوم حذف‌شده در معماری جدید |
| Rendering | ❌ legacy | `template_render_*` با `ReactiveElement.part` + `Observable.computed` — ۷ متد render |
| Example | ❌ legacy | `static renderExampleComponent()` — الگوی قدیمی |
| Step | ❌ ندارد | Step Node وجود ندارد |
| dispose | ❌ ندارد | dispose پیاده‌سازی نشده |
| Category | ❌ ندارد | ثبت در Category نیست |
| ComponentManager | ❌ ندارد | ثبت در ComponentManager نیست |
| Language Keys | ❌ ندارد | کلیدهای زبان در `Keys.ts` / `Fa.ts` / `En.ts` نیست |

### ۱.۲ وابستگی‌های ComponentPositionMenu

| وابستگی | نوع | وضعیت در معماری جدید |
|:---|:---|:---|
| `ComponentFloatMenu` | Composition (has-a) — PositionMenu از FloatMenu برای نمایش منوی شناور استفاده می‌کند | ❌ هنوز مهاجرت نشده — **نیاز به مهاجرت قبلی یا استفاده مستقیم از Category callable** |
| `ComponentButton` | Composition — دکمه‌های Accept/Reject | ✅ مهاجرت شده — `UiCategory.UI.Simples.Button` |
| `ComponentIcon` | Composition — آیکون selector | ✅ مهاجرت شده — `UiCategory.UI.Simples.Icon` |
| `ComponentElementPosition` | Type import در FloatMenu | ❌ هنوز مهاجرت نشده |

**نکته مهم:** `ComponentPositionMenu` به `ComponentFloatMenu` وابسته است که هنوز به معماری جدید مهاجرت نشده. دو راهکار وجود دارد:

1. **پیش‌نیاز:** ابتدا `ComponentFloatMenu` را مهاجرت دهیم (Plan 11.1)
2. **راه‌حل موقت:** در این پلن، `ComponentPositionMenu` به‌جای استفاده مستقیم از `ComponentFloatMenu`، منطق float menu را به‌صورت داخلی پیاده‌سازی کند (inline positioning)

**تصمیم:** در این پلن، از `ComponentFloatMenu` به‌عنوان یک **dependency** استفاده می‌کنیم — به این معنی که `ComponentFloatMenu` باید ابتدا مهاجرت شود (Plan 11.1) یا به‌صورت موقت از Category callable آن استفاده شود. اگر `ComponentFloatMenu` هنوز مهاجرت نشده، `ComponentPositionMenu` می‌تواند با inline positioning کار کند — ولی این پلن فرض می‌کند `ComponentFloatMenu` در دسترس است.

            {
                CLICK: function(event, dataArgs, componentArgs) {
                    const close = this.executeMethod("CLICK_ACCEPT", event, {});
                    if (close) {
                        this.pr_handleMenuClose(false, event);
                    }
                }.bind(this),
            },
        );

        return acceptBtn.getReactiveElement();
    }


    /* ---------------------------------------------
       renderFormFloatMenuBodyButtonsReject — رندر دکمه Reject
       از ComponentButton (Category callable) استفاده می‌کند
    --------------------------------------------- */
    protected renderFormFloatMenuBodyButtonsReject(
        attrsDefault?: any,
        data?:         any,
        extra?:        any,
    ): CoreReactive.App {

        const bind = this._COMPONENT_PROPS_BIND;

        const prop_menuBtnRejectHas   = data?.["prop_menuBtnRejectHas"]   ?? bind.prop_menuBtnRejectHas;
        const prop_menuBtnRejectIcon  = data?.["prop_menuBtnRejectIcon"]  ?? bind.prop_menuBtnRejectIcon;
        const prop_menuBtnRejectTitle = data?.["prop_menuBtnRejectTitle"] ?? bind.prop_menuBtnRejectTitle;

        const rejectBtn = UiCategory.UI.Simples.Button(
            {
                classList: ["col-md-6"],
                prop_btnTitle: prop_menuBtnRejectTitle,
                prop_btnType:  "cancel",
                prop_btnIcon:  prop_menuBtnRejectIcon,
                prop_show:     prop_menuBtnRejectHas,
            },
            {
                CLICK: function(event, dataArgs, componentArgs) {
                    this.pr_handleMenuClose(false, event);
                    this.pr_executeMethodReject(event);
                }.bind(this),
            },
        );

        return rejectBtn.getReactiveElement();
    }


    /// ---------------------
    ///  Private Style Getters
    ///  هر متد یک CoreObservable.App.computed برمی‌گرداند
    ///  توسعه‌پذیر: هر style منطق مستقل دارد
    /// ---------------------

    private getStyleBodyContentHeight(prop_menuBodyHeight) {
        return CoreObservable.App.computed(
            (menuBodyHeight, sizeName) => {
                return UtilStyle.Css_SizeCalc(
                    menuBodyHeight,
                    "-",
                    UtilStyle.Css_BorderWidth(sizeName),
                );
            },
            [prop_menuBodyHeight, CoreConfig.Settings.SizeName.observable()],
            this.getScope(),
        );
    }

    private getStyleBorderBottomStyle(prop_menuBtnAcceptHas, prop_menuBtnRejectHas) {
        return CoreObservable.App.computed(
            (acceptHas, rejectHas) => (acceptHas && rejectHas) ? "solid" : "none",
            [prop_menuBtnAcceptHas, prop_menuBtnRejectHas],
            this.getScope(),
        );
    }

    private getStyleBorderBottomWidth() {
        return CoreObservable.App.computed(
            (sizeName) => UtilStyle.Css_BorderWidth(sizeName),
            [CoreConfig.Settings.SizeName.observable()],
            this.getScope(),
        );
    }

    private getStyleButtonsHeight() {
        return CoreObservable.App.computed(
            (sizeName) => {
                return UtilStyle.Css_SizeCalc(
                    UtilStyle.Css_BorderRadius(sizeName),
                    "+",
                    UtilStyle.Css_Height(sizeName),
                    "+",
                    UtilStyle.Css_BorderRadius(sizeName),
                );
            },
            [CoreConfig.Settings.SizeName.observable()],
            this.getScope(),
        );
    }

    private getStyleButtonsMargin() {
        return CoreObservable.App.computed(
            (sizeName) => UtilStyle.Css_Margin(sizeName),
            [CoreConfig.Settings.SizeName.observable()],
            this.getScope(),
        );
    }


    /// ---------------------
    ///  Private Logic Methods
    /// ---------------------

    private pr_handleMenuClose(checkChild: boolean, event: Event) {
        const target = event.target as HTMLElement;
        const menuId = this.getPartId("part-formFloatMenu");
        if (checkChild && target.closest(`#${menuId}`)) {
            return;
        }

        this.set("prop_menuIsOpen", false);
        this.pr_cleanupDocumentListener();

        if (checkChild) {
            this.pr_executeMethodReject(event);
        }
    }

    private pr_executeMethodReject(event: Event) {
        this.executeMethod("CLICK_REJECT", event, {});
    }

    private pr_cleanupDocumentListener() {
        if (this._ON_MENU_OPEN) {
            document.removeEventListener("click", this._ON_MENU_OPEN);
            this._ON_MENU_OPEN = null;
        }
    }
}
```
