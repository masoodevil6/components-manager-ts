# Plan 13.1.4 — جایگزینی Tooltip inline در ComponentLabel با Composition ComponentTooltip

> **پیش‌نیاز:** Plan 14.1.0 (ComponentTooltip Migration), Plan 13.1.0 (ComponentLabel Migration), Plan 13.1.2 (Fix ComponentLabel Tooltip), Plan 13.1.3 (Fix Tooltip Positioning)
> **هدف:** جایگزینی منطق رندر inline tooltip در `ComponentLabel.renderLabelTooltip` با Composition کامپوننت مستقل `ComponentTooltip` (ساخته‌شده در Plan 14.1.0)
> **اصل:** ComponentLabel نباید خودش FloatMenu/Icon/arrow-position را مدیریت کند — این مسئولیت ComponentTooltip است.

---

## ۰. وضعیت فعلی (Before)

### ۰.۱. رندر tooltip در ComponentLabel (Plan 13.1.2 — inline)

فعلاً `renderLabelTooltip` در `ComponentLabel.ts` (خط ۳۴۱-۴۵۵) تمام منطق tooltip را inline مدیریت می‌کند:

| مسئولیت | کد فعلی | مشکلات |
|:---|:---|:---|
| ساخت آیکون trigger | `new ComponentIcon.Component(...)` inline | تکرار منطق ComponentTooltip |
| محاسبه arrow position | `CoreObservable.App.computed(...)` inline | تکرار منطق ComponentTooltip |
| mapping direction | `TooltipDirectionTypes → FloatMenuDirectionTypes` inline | تکرار |
| Composition FloatMenu | `new ComponentFloatMenu.Component(...)` inline | تکرار |
| anchor styles | `CoreObservable.App.computed(position, dirRtl)` inline | تکرار |
| رندر شرطی | `computed(desc == null → null)` inline | OK — در ComponentLabel باقی می‌ماند |

### ۰.۲. Props tooltip در ComponentLabel

۶ prop tooltip در `ComponentLabel/Props.ts` (خط ۱۰۹-۱۵۱):

| Prop در Label | معادل در Tooltip | Mapping |
|:---|:---|:---|
| `prop_labelTooltipIcon` | `prop_tooltipIcon` | مستقیم |
| `prop_labelTooltipDescription` | `prop_tooltipDescription` | مستقیم |
| `prop_labelTooltipBackground` | `prop_tooltipBackground` | مستقیم |
| `prop_labelTooltipColor` | `prop_tooltipColor` | مستقیم |
| `prop_labelTooltipPosition` | `prop_tooltipIconPosition` | مستقیم |
| `prop_labelTooltipDirection` | `prop_tooltipDirection` | مستقیم (هر دو TooltipDirectionTypes) |

## ۱. تصمیم طراحی

### ۱.۱. Props tooltip در ComponentLabel حفظ می‌شوند

**دلیل:** ComponentLabel یک کامپوننت رابط کاربری است که tooltip به‌عنوان یک feature اختیاری دارد. مصرف‌کننده نباید بداند ComponentTooltip وجود دارد — او `prop_labelTooltip*` را set می‌کند.

| سوال | تصمیم | دلیل |
|:---|:---|:---|
| آیا propهای `prop_labelTooltip*` حذف می‌شوند؟ | **خیر** | API عمومی ComponentLabel حفظ می‌شود |
| آیا Schema `BORDER_CONTENT_TOOLTIP` حذف می‌شود؟ | **خیر** | همچنان part metadata معتبر است |
| آیا `renderLabelTooltip` حذف می‌شود؟ | **خیر** | تبدیل به thin wrapper می‌شود |
| آیا `TooltipDirectionTypes` در Props.ts باقی می‌ماند؟ | **بله** | re-export از ComponentTooltip برای backward compat |

### ۱.۲. `renderLabelTooltip` تبدیل به thin wrapper می‌شود

بدون inline FloatMenu/Icon/arrow — فقط:
1. رندر شرطی (`prop_labelTooltipDescription == null → null`)
2. Composition با `new ComponentTooltip.Component(...)`
3. Mapping propهای `prop_labelTooltip*` → `prop_tooltip*`

## ۲. تغییرات فایل

### ۲.۱. `ComponentLabel.ts` — `renderLabelTooltip` (بازنویسی)

**قبل (Plan 13.1.2 — ۱۱۵ خط inline):**

```typescript
protected renderLabelTooltip(...): CoreReactive.App {
    // ... ۶ prop bind
    // ... tooltipAnchorStyles computed
    // ... tooltip computed (desc, icon, bg, color, pos, dir) => {
    //     ... new ComponentIcon.Component(...)
    //     ... arrowPosition computed
    //     ... new ComponentFloatMenu.Component(...)
    // }
    // ... return section with anchor styles + tooltip children
}
```

**بعد (Plan 13.1.4 — ~۴۰ خط thin wrapper):**

```typescript
protected renderLabelTooltip(
    attrsDefault?: PartAttrDefault,
    data?:         Record<string, CoreObservable.App<any>>,
    extra?:        any,
): CoreReactive.App {

    const bind = this._COMPONENT_PROPS_BIND;

    const prop_labelTooltipIcon        = data?.["prop_labelTooltipIcon"]        ?? bind.prop_labelTooltipIcon;
    const prop_labelTooltipDescription = data?.["prop_labelTooltipDescription"] ?? bind.prop_labelTooltipDescription;
    const prop_labelTooltipBackground  = data?.["prop_labelTooltipBackground"]  ?? bind.prop_labelTooltipBackground;
    const prop_labelTooltipColor       = data?.["prop_labelTooltipColor"]       ?? bind.prop_labelTooltipColor;
    const prop_labelTooltipPosition    = data?.["prop_labelTooltipPosition"]    ?? bind.prop_labelTooltipPosition;
    const prop_labelTooltipDirection   = data?.["prop_labelTooltipDirection"]   ?? bind.prop_labelTooltipDirection;

    // Plan 13.1.4 — anchor styles (مانند قبل — position absolute نسبت به parent)
    const tooltipAnchorStyles = CoreObservable.App.computed(
        (position: ReturnType<typeof UtilStyle.Css_SizeUnit>, dirRtl: boolean) => ({
            position: "absolute",
            top:      "0",
            ...(dirRtl ? {left: position} : {right: position}),
        }),
        [prop_labelTooltipPosition, CoreConfig.Settings.DirectionRtl.observable()],
        this.getScope(),
    );

    // Plan 13.1.4 — Composition با ComponentTooltip (نه inline FloatMenu/Icon)
    // رندر شرطی: if (prop_labelTooltipDescription == null) → null
    const tooltip = CoreObservable.App.computed(
        (desc, icon, bg, color, pos, dir) => {
            if (desc == null) return null;

            // Mapping propهای Label → Tooltip
            return new ComponentTooltip.Component(
                {
                    prop_tooltipIcon:          icon,
                    prop_tooltipDescription:    desc,
                    prop_tooltipBackground:     bg,
                    prop_tooltipColor:          color,
                    prop_tooltipIconPosition:   pos,
                    prop_tooltipDirection:      dir,
                } as any,
                {},
            ).getReactiveElement();
        },
        [
            prop_labelTooltipDescription,
            prop_labelTooltipIcon,
            prop_labelTooltipBackground,
            prop_labelTooltipColor,
            prop_labelTooltipPosition,
            prop_labelTooltipDirection,
        ],
        this.getScope(),
    );

    return CoreReactive.App.section({
        attrs: {...attrsDefault},
        stylesBind: tooltipAnchorStyles,
        children: [tooltip],
    });
}
```

### ۲.۲. `ComponentLabel.ts` — Imports (به‌روزرسانی)

**حذف:**
```typescript
import * as ComponentFloatMenu from "../componentFloatMenu";
import {DirectionTypes as FloatMenuDirectionTypes, ShowTypes as FloatMenuShowTypes} from "../componentFloatMenu";
```

**افزودن:**
```typescript
import * as ComponentTooltip from "../componentTooltip";
```

**حذف متدهای private که دیگر استفاده نمی‌شوند:**
- `getIconSizeValue()` — منتقل به ComponentTooltip (Plan 14.1.0)

### ۲.۳. `ComponentLabel/Props.ts` — re-export TooltipDirectionTypes

```typescript
// Plan 13.1.4 — re-export از ComponentTooltip برای backward compat
```

## ۳. جریان رندر (After)

```
ComponentLabel
  → renderContentComponent → executeSchemaPart(BORDER)
    → renderLabelBorder → ComponentBorder
      → prop_content = executeSchemaPart(BORDER_CONTENT)
        → renderLabelContent
          → children: [TITLE, TOOLTIP]
            → executeSchemaPart(BORDER_CONTENT_TOOLTIP)
              → renderLabelTooltip
                → if (desc == null) → null
                → else → new ComponentTooltip.Component({
                    prop_tooltipIcon:        prop_labelTooltipIcon,
                    prop_tooltipDescription: prop_labelTooltipDescription,
                    prop_tooltipBackground:  prop_labelTooltipBackground,
                    prop_tooltipColor:       prop_labelTooltipColor,
                    prop_tooltipIconPosition: prop_labelTooltipPosition,
                    prop_tooltipDirection:   prop_labelTooltipDirection,
                  })
                  → ComponentTooltip.renderContentComponent
                    → executeSchemaPart(FLOAT_MENU)
                      → renderTooltipFloatMenu
                        → new ComponentFloatMenu.Component(...)
                          → ComponentBorder (popup)
```
