# Plan 8.2.5 — Getter Methods برای ClReactiveElement

> **پیش‌نیاز:** —
> **هدف:** افزودن متدهای getter برای خواندن `attr`, `style`, `className` از ClReactiveElement

## زمینه

در حال حاضر `ClReactiveElement` فقط متدهای setter داخلی (`_applyAttrs`, `_applyStyles`, `_applyClassName`) دارد — همه از طریق constructor `options` تنظیم می‌شوند. متد عمومی برای **خواندن** مقادیر فعلی وجود ندارد.

### نیاز

مصرف‌کننده (Component یا test) نیاز دارد مقادیر فعلی را بخواند:
- `getAttr("role")` → `"alert"`
- `getStyle("color")` → `"red"`
- `getClassName()` → `"d-flex flex-column gap-2"`
- `hasClass("d-flex")` → `true`

## متدهای پیشنهادی

### ۱. Attr Getters

```typescript
/**
 * خواندن مقدار یک attribute
 * @param name — نام attribute (مثل "role", "data-id")
 * @returns مقدار attribute یا null اگر وجود نداشته باشد
 */
getAttr(name: string): string | null {
    return this.element.getAttribute(name);
}

/**
 * بررسی وجود یک attribute
 * @param name — نام attribute
 * @returns true اگر attribute وجود داشته باشد
 */
hasAttr(name: string): boolean {
    return this.element.hasAttribute(name);
}
```

### ۲. Style Getters

```typescript
/**
 * خواندن مقدار یک style property
 * @param key — نام CSS property (مثل "color", "border-width", "--custom")
 * @returns مقدار style یا رشته خالی اگر تنظیم نشده باشد
 *
 * نکته: برای CSS custom properties (--var) از getPropertyValue استفاده می‌شود.
 *       برای regular properties از style[key] خوانده می‌شود.
 */
getStyle(key: string): string {
    if (key.startsWith("--")) {
        return this.element.style.getPropertyValue(key);
    }
    // تبدیل kebab-case به camelCase برای دسترسی via style object
    const camelKey = key.replace(/-([a-z])/g, (_, c) => c.toUpperCase());
    return (this.element.style as any)[camelKey] || "";
}

/**
 * بررسی وجود یک style property (تنظیم‌شده و غیر خالی)
 * @param key — نام CSS property
 * @returns true اگر style تنظیم شده و مقدار غیر خالی داشته باشد
 */
hasStyle(key: string): boolean {
    return this.getStyle(key) !== "";
}
```

### ۳. ClassName Getters

```typescript
/**
 * خواندن لیست classهای فعلی
 * @returns آرایه از class names
 */
getClassName(): string[] {
    return Array.from(this.element.classList);
}

/**
 * بررسی وجود یک class
 * @param name — نام class
 * @returns true اگر class وجود داشته باشد
 */
hasClass(name: string): boolean {
    return this.element.classList.contains(name);
}
```

## نکات مهم

### چرا فقط getter؟

این پلن فقط **خواندن** مقادیر را پوشش می‌دهد. متدهای setter (مثل `setAttr`, `setStyle`, `addClass`) در پلن جداگانه‌ای بررسی می‌شوند — چون setterها نیاز به reactive binding management دارند (unsubscribe قبلی، subscribe جدید).

### getStyle و CSS custom properties

CSS custom properties (`--var`) با regular properties متفاوت هستند:
- Regular: `element.style.color` یا `element.style["color"]`
- Custom: `element.style.getPropertyValue("--my-var")`

`getStyle` هر دو را پشتیبانی می‌کند.

### getStyle و kebab-case

CSS properties در DOM به‌صورت camelCase ذخیره می‌شوند:
- `border-width` → `borderWidth`
- `background-color` → `backgroundColor`

`getStyle` تبدیل kebab-case → camelCase را انجام می‌دهد تا مصرف‌کننده بتواند با هر دو فرمت کار کند.

### بازگشت `this` در getterها؟

خیر — getterها مقدار برمی‌گردانند، نه `this`. این الگوی متداول getter است. متدهای chainable (مثل `on`/`off`) `this` برمی‌گردانند ولی getterها مقدار.
