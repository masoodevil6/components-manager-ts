# Plan 8.2 — ساخت ComponentMessages

> **به‌روزرسانی:** ۹/۱/۲۶ — تطبیق با Plan 8.1.2 (Trait Composition), 8.1.4 (Methods API), 8.1.5 (ComponentExample با render())

## هدف

ساخت اولین Component واقعی با معماری جدید — `ComponentMessages`.

این Component یک لیست از پیام‌ها (success / warning / error / custom) را نمایش می‌دهد، هر پیام قابل بستن است.

---

## تحلیل Component قدیمی

### فایل منبع
`last/tools/components/ComponentMessages.ts`

### Props (۷ prop اختصاصی)

| Prop | Type | Default | کاربرد |
|:---|:---|:---|:---|
| `prop_type` | `MessageTypes` (enum) | `SUCCESS` | نوع پیام‌ها |
| `prop_messages` | `string[]` | `[]` | لیست پیام‌ها |
| `prop_borderWidth` | `string` | `"xs"` | ضخامت border |
| `prop_iconColor` | `string \| null` | `null` | رنگ آیکون (custom) |
| `prop_borderColor` | `string \| null` | `null` | رنگ border (custom) |
| `prop_backgroundColor` | `string \| null` | `null` | رنگ پس‌زمینه (custom) |
| `prop_textColor` | `string \| null` | `null` | رنگ متن (custom) |

```typescript

    CUSTOM  = "custom",

```

### Schemas (۲ part اختصاصی)

| Part | کاربرد |
|:---|:---|
| `part-messages-message` | رندر لیست پیام‌ها |
| `part-messages-icon` | رندر آیکون بستن هر پیام |

### Methods (۱ method)

| Method | Semantic Key | کاربرد |
|:---|:---|:---|
| `fn_onCloseMessage` | `CLOSE_MESSAGE` | وقتی کاربر روی آیکون بستن کلیک می‌کند |

### وابستگی‌ها

- `ComponentIcon` — برای آیکون بستن (✅ ساخته‌شده در Plan 8.1)
- `ComponentStructureTrait` — برای ۷ prop پایه + renderContent (✅ Plan 8.1.2)
- `UiIcons` — برای آیکون close
- CSS variables — برای رنگ‌ها (`var(--successColor1)`, ...)

## معماری جدید

### اصل معماری (Plan 8.1.2 — Trait Composition)

```
ComponentMessages HAS-A ComponentStructure (نه IS-A)
```

`ComponentMessages` از `CoreComponents.App` ارث می‌برد (نه از `ComponentStructure`).
`ComponentStructure` به‌عنوان فرزند در `renderContentComponent` ساخته می‌شود —
با `content = renderMessages` (محتوای اختصاصی ComponentMessages).

۷ prop پایه از `ComponentStructureTrait.props` در `_COMPONENT_PATTERN` ثبت می‌شوند.
در `renderContentComponent` از `ComponentStructureTrait.renderContent()` استفاده می‌شود
که ComponentStructure را می‌سازد و propهای پایه را forward می‌کند.

### فایل ۴ — Methods.ts (Plan 8.1.4 — Methods API کامل)

```typescript
import {Props as MessagesProps} from "./Props";
// --------------------------------

/**
 * Methods اختصاصی ComponentMessages
 *
 * سه مسئولیت:
 *   1. تعریف semantic method keys (CLOSE_MESSAGE) — Public API
 *   2. نگهداری runtime method name (fn_onCloseMessage) — implementation
 *   3. تعریف metadata مربوط به Component/Data Args — source of truth
 *
 * Plan 8.1.4:
 *   - semantic keys متعلق به Public API هستند
 *   - runtime name متعلق به implementation است
 *   - args و dataArgs در اینجا تعریف می‌شوند و type‌ها از آنجا استخراج می‌شوند
 */
export const Methods = {

    CLOSE_MESSAGE: {
        name:        "fn_onCloseMessage",
        description: "Callback when a message is closed",

        // componentArgs — prop reference‌ها
        // در زمان اجرا resolve می‌شوند به مقادیر فعلی props
        args: {
            TYPE:     MessagesProps.prop_type,
            MESSAGES: MessagesProps.prop_messages,
        },

        // dataArgs — type تعریف‌شده برای داده‌های runtime
        // هر پیام دارای index و text است
        dataArgs: {
            MESSAGE_INDEX: 0 as number,
            MESSAGE_TEXT:  "" as string,
            MESSAGE_TYPE:  "" as string,
        } as const,
    },

} as const;


/**
 * نوع methodهای ComponentMessages — برای استفاده در TMethods (داخلی Component)
 */
export type MethodsType = {
    [K in keyof typeof Methods]: (event: Event, dataArgs: any, componentArgs: any) => void
};


/**
 * Component Args type برای هر method
 * از args (prop reference) استخراج می‌شود
 *
 * مثال: MethodsComponentArgs["CLOSE_MESSAGE"] = { TYPE: MessageTypes, MESSAGES: string[] }
 */
export type MethodsComponentArgs = {
    [K in keyof typeof Methods]: {
        [ArgKey in keyof typeof Methods[K]["args"]]:
            typeof Methods[K]["args"][ArgKey] extends {
                default: infer T
            }
                ? T
                : any;
    };
};


/**
 * Data Args type برای هر method
 * از dataArgs تعریف‌شده در Methods استخراج می‌شود
 *
 * مثال: MethodsDataArgs["CLOSE_MESSAGE"] = { MESSAGE_INDEX: number, MESSAGE_TEXT: string, MESSAGE_TYPE: string }
 */
export type MethodsDataArgs = {
    [K in keyof typeof Methods]: typeof Methods[K]["dataArgs"];
};


/**
 * نوع config methods برای مصرف‌کننده (Category callable)
 *
 * کلیدهای Public (semantic) از keyof typeof Methods استخراج می‌شوند.
 * هر method callback با type‌های کامل برای autocomplete:
 *   - event: Event
 *   - dataArgs: MethodsDataArgs[K] | null
 *   - componentArgs: MethodsComponentArgs[K] | null
 *   - this: TThis (Component instance)
 *
 * استفاده:
 *   UiCategory.UI.Simples.Messages(
 *       { prop_type: "warning", prop_messages: [...] },
 *       {
 *           CLOSE_MESSAGE: function(event, dataArgs, componentArgs) {
 *               // autocomplete:
 *               //   componentArgs?.TYPE     ← MessageTypes
 *               //   componentArgs?.MESSAGES ← string[]
 *               //   dataArgs?.MESSAGE_INDEX ← number
 *               //   dataArgs?.MESSAGE_TEXT  ← string
 *               //   dataArgs?.MESSAGE_TYPE  ← string
 *               //   this                    ← ComponentMessages (fn.call(this, ...))
 *           },
 *       },
 *       { unique, emit, events },
 *   );
 *
 * نکته: برای استفاده از `this` به‌عنوان Component instance، از `function` استفاده شود.
 * Arrow function با `.call()` نمی‌تواند `this` را تغییر دهد.
 */
export type MethodsConfigType<
    TThis = any,
> = {
    [K in keyof typeof Methods]?: (
        this: TThis,
        event: Event,
        dataArgs: MethodsDataArgs[K] | null,
        componentArgs: MethodsComponentArgs[K] | null,
    ) => void;
};
```

### فایل ۶ — ComponentMessagesBase.ts (Plan 8.1.2 — Trait Composition)

```typescript
import * as CoreComponents   from "@/core_components";
// --------------------------------
import {ComponentStructureTrait} from "../../traits/componentStructureTrait";
// --------------------------------
import {Props,     PropsType}     from "./Props";
import {Schemas,   SchemasType}   from "./Schemas";
import {Methods,   MethodsType}   from "./Methods";
import {Definition}               from "./Definition";


/**
 * ComponentMessagesBase — ترکیب config پایه و اختصاصی
 *
 * ارث از CoreComponents.App (ClComponentBase) — نه ComponentStructure.
 * ComponentMessages خودش یک Component مستقل است.
 * ComponentStructure به‌عنوان فرزند در renderContentComponent استفاده می‌شود.
 *
 * ۷ prop پایه ComponentStructure از ComponentStructureTrait.props در _COMPONENT_PATTERN
 * ثبت می‌شوند تا کاربر بتواند آن‌ها را set کند — سپس در renderContentComponent
 * به ComponentStructure.create() forward می‌شوند.
 */
export class ComponentMessagesBase extends CoreComponents.App<
    PropsType & Record<string, any>,
    SchemasType,
    any,
    MethodsType
> {

    protected _COMPONENT_DEFINITION = Definition;

    // ۷ prop پایه (از Trait) + ۷ prop اختصاصی ComponentMessages
    protected _COMPONENT_PATTERN = CoreComponents.DefineProp<PropsType & Record<string, any>>({
        ...ComponentStructureTrait.props,
        ...Props,
    } as any);

    protected _COMPONENT_SCHEMA = CoreComponents.DefineSchema<SchemasType, PropsType & Record<string, any>>({
        ...Schemas,
    } as any);

    protected _COMPONENT_METHODS = CoreComponents.DefineMethod<MethodsType, PropsType & Record<string, any>>({
        ...Methods,
    } as any);

}
```

### فایل ۷ — ComponentMessages.ts

```typescript
import * as CoreReactive   from "@/core_reactive";
import * as CoreObservable from "@/core_observable";
// --------------------------------
import {ComponentMessagesBase}  from "./ComponentMessagesBase";
import {MessagesStep}           from "./Step";
import {Schemas}                from "./Schemas";
import {MethodsType,
        MethodsConfigType}      from "./Methods";
import {PropsType, MessageTypes} from "./Props";
import {PartAttrDefault}        from "@/core_components";
import {ComponentStructureTrait} from "../../traits/componentStructureTrait";
import {PropsType as StructurePropsType} from "../componentStructure/Props";
// --------------------------------
import * as UiCategory  from "@/ui_categories";
import * as UiIcons     from "@/ui_icons";


/**
 * ComponentMessages — کلاس نهایی
 *
 * معماری Composition:
 *   ComponentMessages HAS-A ComponentStructure (نه IS-A)
 *   ComponentStructure در renderContentComponent ساخته می‌شود
 *   و content آن = renderMessages (محتوای اختصاصی ComponentMessages)
 *
 * Constructor امضا: (config, methods, identity?)
 *   config  — شامل propهای پایه (classList, prop_show, ...) + propهای اختصاصی (prop_type, prop_messages, ...)
 *   methods — methodهای اختصاصی (CLOSE_MESSAGE) با type-safe callback
 *   identity — { unique?, emit?, events? }
 */
export class ComponentMessages extends ComponentMessagesBase {

    constructor(
        config?:  Partial<StructurePropsType & PropsType>,
        methods?: MethodsConfigType<ComponentMessages>,
        identity?: {
            unique?: any;
            emit?:   any;
            events?: Record<string, any> | null;
        },
    ) {
        super("messages", null);

        // identity را manual set می‌کنیم (ClComponentBase constructor identity نمی‌گیرد)
        this._COMPONENT_UNIQUE = identity?.unique ?? null;
        this._COMPONENT_EMIT   = identity?.emit ?? null;

        this.renderComponent(
            config as any,
            methods as any,
            identity?.events ?? null,
        );
    }


    /* ---------------------------------------------
       renderContentComponent — ساخت ComponentStructure
       با content = renderMessages (محتوای اختصاصی ComponentMessages)

       پیاده‌سازی از طریق ComponentStructureTrait —
       Trait مسئول ساخت ComponentStructure و forward propهای پایه است.
       Component فقط content اختصاصی خود را تعیین می‌کند.
    --------------------------------------------- */
    override renderContentComponent(): CoreReactive.App {
        return ComponentStructureTrait.renderContent(
            this,
            () => this.renderMessages(),
        );
    }


    /* ---------------------------------------------
       renderManagerComponent — Routing
       partهای اختصاصی ComponentMessages را مدیریت می‌کند.
    --------------------------------------------- */
    override renderManagerComponent(
        partName:     string,
        attrsDefault: PartAttrDefault,
        data:         Record<string, CoreObservable.App<any>>,
        extra:        any,
    ): CoreReactive.App {

        switch (partName) {
            case Schemas.MESSAGE.part:
                // renderContentComponent یک ComponentStructure می‌سازد
                // با content = renderMessages — این یعنی prop_show / classList / etc.
                // از ComponentMessages به ComponentStructure forward می‌شوند.
                return this.renderContentComponent();
            default:
                return super.renderManagerComponent(partName, attrsDefault, data, extra);
        }
    }


    /* ---------------------------------------------
       renderMessages — رندر لیست پیام‌ها
       هر پیام: <section role="alert"> + <div.alert> + <b>{msg}</b> + ICON
       رنگ‌ها بر اساس prop_type (success/warning/error/custom)
    --------------------------------------------- */
    protected renderMessages(
        attrsDefault?: PartAttrDefault,
        data?:         Record<string, CoreObservable.App<any>>,
    ): CoreReactive.App {

        const prop_type            = data?.["prop_type"]            ?? this._COMPONENT_PROPS_BIND.prop_type;
        const prop_messages        = data?.["prop_messages"]        ?? this._COMPONENT_PROPS_BIND.prop_messages;
        const prop_borderWidth     = data?.["prop_borderWidth"]     ?? this._COMPONENT_PROPS_BIND.prop_borderWidth;
        const prop_backgroundColor = data?.["prop_backgroundColor"] ?? this._COMPONENT_PROPS_BIND.prop_backgroundColor;
        const prop_textColor       = data?.["prop_textColor"]       ?? this._COMPONENT_PROPS_BIND.prop_textColor;
        const prop_borderColor     = data?.["prop_borderColor"]     ?? this._COMPONENT_PROPS_BIND.prop_borderColor;

        // رندر لیست پیام‌ها با prop_messages.mapArray
        // هر پیام: <section role="alert"> + <div.alert> + <b>{msg}</b> + ICON
        // رنگ‌ها بر اساس prop_type (success/warning/error/custom)
        // ... (مطابق پیاده‌سازی قدیم ولی با CoreReactive.App)

        return CoreReactive.App.div({
            className: ["d-flex", "flex-column", "gap-2"],
            children: [
                prop_messages.mapArray((messageText: string, index: number) =>
                    this.renderSingleMessage(messageText, index, prop_type, {
                        prop_borderWidth,
                        prop_backgroundColor,
                        prop_textColor,
                        prop_borderColor,
                    }),
                ),
            ],
        });
    }


    /* ---------------------------------------------
       renderSingleMessage — رندر یک پیام
    --------------------------------------------- */
    protected renderSingleMessage(
        messageText: string,
        index:       number,
        prop_type:   CoreObservable.App<MessageTypes>,
        styles:      Record<string, any>,
    ): CoreReactive.App {

        // رنگ‌ها بر اساس type
        const alertClass = prop_type.map((type: MessageTypes) => {
            switch (type) {
                case MessageTypes.SUCCESS: return "alert-success";
                case MessageTypes.WARNING: return "alert-warning";
                case MessageTypes.ERROR:   return "alert-danger";
                case MessageTypes.CUSTOM:  return "alert-secondary";
                default:                   return "alert-secondary";
            }
        });

        return CoreReactive.App.section({
            attrs: { role: "alert" },
            classBind: [alertClass],
            className: ["d-flex", "align-items-center", "gap-2", "p-2", "rounded"],
            children: [
                `<b>${messageText}</b>`,
                this.renderCloseIcon(index, messageText, prop_type),
            ],
        });
    }


    /* ---------------------------------------------
       renderCloseIcon — رندر ComponentIcon برای بستن پیام
       on click → this.executeMethod("CLOSE_MESSAGE", ...)
    --------------------------------------------- */
    protected renderCloseIcon(
        index:      number,
        messageText: string,
        prop_type:  CoreObservable.App<MessageTypes>,
    ): CoreReactive.App {

        // استفاده از Category callable (الگوی رسمی)
        const iconElement = UiCategory.UI.Simples.Icon(
            {
                prop_icon:      UiIcons.CreateIcon(UiIcons.Src.StatusClose.Definition, { size: 16 }),
                prop_iconClass: ["cursor-pointer", "ms-auto"],
                prop_iconStyles: { "inset-inline-end": "5px", "top": "5px" },
            },
            {
                CLICK: (event: Event) => {
                    event.preventDefault();
                    this.executeMethod("CLOSE_MESSAGE", event, {
                        MESSAGE_INDEX: index,
                        MESSAGE_TEXT:  messageText,
                        MESSAGE_TYPE:  prop_type.get(),
                    });
                },
            },
        ).getElement();

        return CoreReactive.App.part("span", {
            children: [iconElement],
        });
    }


}
```

```typescript
import {ComponentExample} from "@/core_components";
// --------------------------------
import {SuccessExample}  from "./Success";

/**
 * Examples Registry برای ComponentMessages
 *
 * تمام Exampleهای ComponentMessages از این نقطه قابل دسترسی هستند.
 * ComponentManager می‌تواند این Registry را بخواند و
 * Exampleها را با example.render() نمایش دهد.
 *
 * @example
 *   Examples.SUCCESS.render()   // → HTMLElement
 *   Examples.WARNING.render()   // → HTMLElement
```

## نکات مهم

### وابستگی به ComponentIcon

`ComponentMessages` برای آیکون بستن هر پیام از `ComponentIcon` استفاده می‌کند.
`ComponentIcon` در Plan 8.1 ساخته شده و قابل استفاده است.

**استفاده (الگوی رسمی — Category callable):**
```typescript
import * as UiCategory  from "@/ui_categories";
import * as UiIcons     from "@/ui_icons";

const iconElement = UiCategory.UI.Simples.Icon(
    {
        prop_icon:      UiIcons.CreateIcon(UiIcons.Src.StatusClose.Definition, { size: 16 }),
        prop_iconClass: ["cursor-pointer", "ms-auto"],
        prop_iconStyles: { "inset-inline-end": "5px", "top": "5px" },
    },
    {
        CLICK: (event: Event) => {
            event.preventDefault();
            this.executeMethod("CLOSE_MESSAGE", event, { ... });
        },
    },
).getElement();
```

### الگوی Trait Composition (Plan 8.1.2)

`ComponentMessages` از `ComponentStructureTrait` استفاده می‌کند:
- `ComponentStructureTrait.props` — ۷ prop پایه در `_COMPONENT_PATTERN`
- `ComponentStructureTrait.renderContent(this, () => this.renderMessages())` — ساخت ComponentStructure با content اختصاصی

این الگو از "MegaComponent" anti-pattern جلوگیری می‌کند — Componentها از Traitها capability می‌گیرند
بدون اینکه از ComponentStructure ارث ببرند.

### رنگ‌ها

پیاده‌سازی قدیمی از CSS variables استفاده می‌کرد:
- `var(--successColor1)`, `var(--errorColor1)`, `var(--warningColor1)`

این الگو حفظ می‌شود — تغییر نمی‌کند. در نسخه جدید از Bootstrap alert classes استفاده می‌کنیم:
- `alert-success`, `alert-warning`, `alert-danger`, `alert-secondary`
