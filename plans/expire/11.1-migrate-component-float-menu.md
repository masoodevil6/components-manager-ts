## ۰. اصول قابل‌نگهداری و توسعه‌پذیری توسط انسان (الگوی componentButton)

این پلن از الگوهای `componentButton` برای اطمینان از قابل‌نگهداری و توسعه‌پذیری توسط انسان پیروی می‌کند:

### ۰.۱ ساختار فایل‌ها — JSDoc و Section Grouping

| الگو | توضیح | مثال از componentButton |
|:---|:---|:---|
| **JSDoc روی کلاس** | هر کلاس JSDoc با توضیح معماری، Plan reference، و behavior | `ComponentButton` JSDoc شامل Composition architecture + Plan 9.1.1 behavior |
| **JSDoc روی فیلدها** | هر فیلد `protected` / `private` JSDoc دارد | `_HOVER_STATE` — "معادل el.hover قدیمی" |
| **JSDoc روی متدها** | هر متد `protected` / `private` JSDoc دارد | `renderButton`, `renderButtonTitle`, `renderButtonIcon` |
| **Section grouping در Props** | `/// --- Group Name ---` برای دسته‌بندی propها | `/// --- موجود (حفظ) ---` در Props.ts |
| **JSDoc روی enumها** | هر enum JSDoc با توضیح کاربرد | `ButtonSemantic` — "نوع معنایی دکمه" |
| **JSDoc روی type exports** | هر type export JSDoc با usage example | `MethodsConfigType` با مثال `UiCategory.UI.Simples.Button(...)` |
| **`satisfies` keyword** | type safety بدون widening | `satisfies CoreComponents.ComponentProps` |

### ۰.۲ الگوی Render Methods — `protected` برای توسعه‌پذیری

```typescript
// ✅ الگوی componentButton — protected (قابل override توسط فرزند)
protected renderSelector(...): CoreReactive.App { ... }

// ❌ anti-pattern — private (غیرقابل توسعه)
private renderSelector(...): CoreReactive.App { ... }
```

هر render method:
1. `protected` است (فرزند می‌تواند override کند)
2. ابتدا `const bind = this._COMPONENT_PROPS_BIND;` — دسترسی به prop bindings
3. سپس `const prop_xxx = data?.["prop_xxx"] ?? bind.prop_xxx;` — resolution با fallback
4. در نهایت `CoreReactive.App.section/button/part(...)` — ساخت ReactiveElement

### ۰.۳ الگوی Style Getters — `private` و کوچک

هر style getter:
1. `private` است (implementation detail)
2. فقط یک style را مدیریت می‌کند (single responsibility)
3. `CoreObservable.App.computed(...)` برمی‌گرداند
4. ورودی‌هایش prop bindings هستند (نه مقدار خام)
5. `this.getScope()` برای scope binding

```typescript
// ✅ الگوی componentButton — هر getter یک style
private getStyleBtnHeight(prop_btnHeight) {
    return CoreObservable.App.computed(
        (heightProp, sizeName) => heightProp ?? UtilStyle.Css_Height(sizeName),
        [prop_btnHeight, CoreConfig.Settings.SizeName.observable()],
        this.getScope(),
    );
}
```

## ۱. وضعیت فعلی

### ۱.۲ وابستگی‌های ComponentFloatMenu

| وابستگی | نوع | وضعیت در معماری جدید |
|:---|:---|:---|
| `ComponentElementPosition` | Composition (has-a) — FloatMenu از ElementPosition برای positioning استفاده می‌کند | ❌ هنوز مهاجرت نشده — **پیش‌نیاز** |
| `ComponentBorder` | Composition (has-a) — FloatMenu از Border برای حاشیه + arrow استفاده می‌کند | ✅ مهاجرت شده — `UiCategory.UI.Contents.Border` |

**نکته مهم:** `ComponentFloatMenu` به `ComponentElementPosition` وابسته است که هنوز مهاجرت نشده. دو راهکار:

1. **پیش‌نیاز:** ابتدا `ComponentElementPosition` را مهاجرت دهیم (Plan 11.0)
2. **راه‌حل موقت:** در `ComponentFloatMenu` به‌جای استفاده از `ComponentElementPosition`، منطق positioning را inline پیاده‌سازی کنیم (CSS `position: absolute` + `z-index`)

**تصمیم:** در این پلن، راهکار B (inline positioning) را پیشنهاد می‌کنیم — چون منطق positioning در FloatMenu ساده است (absolute positioning با direction-based offsets) و وابستگی به ComponentElementStatus را حذف می‌کند. اگر ComponentElementPosition در آینده مهاجرت شود، می‌توان FloatMenu را refactor کرد.

### ۲.۱ الگوی مرجع

الگوی `componentButton` و `componentBorder` به‌عنوان مرجع اصلی استفاده می‌شود — با تفاوت‌های اختصاصی FloatMenu:
- ComponentFloatMenu یک **composite component** است (selector + positioning + border with arrow)
- ۳ schema part دارد — routing در `renderManagerComponent`
- از `ComponentBorder` به‌عنوان فرزند استفاده می‌کند (Composition)

- direction-based positioning logic (top/bottom/left/right)
- hover/click show type logic
- هیچ methodی ندارد (presentational)

### Phase ۷ — `ComponentFloatMenu.ts`

الگوی `ComponentButton.ts` / `ComponentBorder.ts` با ۳ render method برای ۳ schema part:

**نکته کلیدی:** در legacy، FloatMenu از `ComponentElementPosition` برای positioning استفاده می‌کند. در این پلن، منطق positioning را **inline** پیاده‌سازی می‌کنیم — یعنی به‌جای `new ComponentElementPosition(...)`، یک `CoreReactive.App.section` با `position: absolute` و direction-based offsets ایجاد می‌کنیم.

```typescript
import * as CoreReactive   from "@/core_reactive";
import * as CoreObservable from "@/core_observable";
import * as CoreConfig     from "@/core_configs";
import * as UtilStyle      from "@/util_styles";
import * as UtilConst      from "@/util_consts";
// --------------------------------
import {ComponentFloatMenuBase}     from "./ComponentFloatMenuBase";
import {createFloatMenuStep}        from "./Step";
import {Schemas}                    from "./Schemas";
import {DirectionTypes, ShowTypes}  from "./Props";
import {MethodsConfigType}          from "./Methods";
import {PropsType}                  from "./Props";
import {ComponentStructureTrait}    from "../../traits/componentStructureTrait";
import {PropsType as StructurePropsType} from "../componentStructure/Props";
// --------------------------------
import * as UiCategory  from "@/ui_categories";
import * as UIComponents from "@/ui_components";
import {ArrowTypes}     from "../componentBorder/Props";


export class ComponentFloatMenu extends ComponentFloatMenuBase {

    /* ---------------------------------------------
       Internal State
    --------------------------------------------- */
    private _IS_SHOW: boolean = false;


    constructor(
        config?:  Partial<StructurePropsType & PropsType>,
        methods?: MethodsConfigType<ComponentFloatMenu>,
        identity?: {
            unique?: any;
            emit?:   any;
            events?: Record<string, any> | null;
        },
    ) {
        const step = createFloatMenuStep();

        super("float-menu", null, identity, step);

        this.renderComponent(
            config as any,
            methods as any,
            identity?.events ?? null,
        );
    }


    /* ---------------------------------------------
       Plan 8.2.7 — Component Disposal
    --------------------------------------------- */
    dispose(): void {
        this.disposeStep();
    }


    /* ---------------------------------------------
       Plan 8.2.10 — renderContentComponent از Trait
    --------------------------------------------- */
    override renderContentComponent(
        attrsDefault?: any,
        data?:         any,
        extra?:        any,
    ): CoreReactive.App {
        return ComponentStructureTrait.renderContent(
            this,
            () => this.executeSchemaPart(Schemas.SELECTOR.part, {}),
        );
    }


    /* ---------------------------------------------
       renderManagerComponent — Routing برای ۳ part
    --------------------------------------------- */
    override renderManagerComponent(
        partName:     string,
        attrsDefault: any,
        data:         any,
        extra?:       any,
    ): CoreReactive.App {

        switch (partName) {
            case Schemas.SELECTOR.part:
                return this.renderSelector(attrsDefault, data, extra);
            case Schemas.SELECTOR_POSITION.part:
                return this.renderSelectorPosition(attrsDefault, data, extra);
            case Schemas.SELECTOR_POSITION_BORDER.part:
                return this.renderSelectorPositionBorder(attrsDefault, data, extra);
            default:
                return super.renderContentComponent(attrsDefault, data, extra);
        }
    }


    /* ---------------------------------------------
       renderSelector — رندر بخش selector (trigger)
       شامل content + position child
       مدیریت hover/click show types
    --------------------------------------------- */
    protected renderSelector(
        attrsDefault?: any,
        data?:         any,
        extra?:        any,
    ): CoreReactive.App {

        const bind = this._COMPONENT_PROPS_BIND;

        const prop_selectorContent         = data?.["prop_selectorContent"]         ?? bind.prop_selectorContent;
        const prop_selectorClass           = data?.["prop_selectorClass"]           ?? bind.prop_selectorClass;
        const prop_selectorStyles          = data?.["prop_selectorStyles"]          ?? bind.prop_selectorStyles;
        const prop_selectorShowType        = data?.["prop_selectorShowType"]        ?? bind.prop_selectorShowType;
        const prop_floatShowControlWithSelf = data?.["prop_floatShowControlWithSelf"] ?? bind.prop_floatShowControlWithSelf;

        return CoreReactive.App.section({
            attrs: {
                ...attrsDefault,
            },
            styles: this.getStyleSelector(),
            stylesBind: {
                prop_selectorStyles,
            },
            classBind: [
                prop_selectorClass,
            ],
            className: [
                "d-block", "w-100", "h-100",
            ],
            on: {
                click: (event: Event) => {
                    CoreObservable.App.computed(
                        (selectorTypeShow, floatShowControlWithSelf) => {
                            if (!floatShowControlWithSelf) {
                                if (selectorTypeShow === ShowTypes.CLICK) {
                                    this._IS_SHOW = !this._IS_SHOW;
                                    this.set("prop_floatIsShow", this._IS_SHOW);
                                }
                            }
                        },
                        [prop_selectorShowType, prop_floatShowControlWithSelf],
                        this.getScope(),
                    );
                },

                mouseenter: (event: Event) => {
                    CoreObservable.App.computed(
                        (selectorTypeShow) => {
                            if (selectorTypeShow === ShowTypes.HOVER) {
                                this.set("prop_floatIsShow", true);
                            }
                        },
                        [prop_selectorShowType],
                        this.getScope(),
                    );
                },

                mouseleave: (event: Event) => {
                    CoreObservable.App.computed(
                        (selectorTypeShow) => {
                            if (selectorTypeShow === ShowTypes.HOVER) {
                                this.set("prop_floatIsShow", false);
                            }
                        },
                        [prop_selectorShowType],
                        this.getScope(),
                    );
                },
            },
            children: [
                prop_selectorContent,
                this.executeSchemaPart(Schemas.SELECTOR_POSITION.part, {}),
            ],
        });
    }


    /* ---------------------------------------------
       renderSelectorPosition — رندر بخش positioning
       Inline positioning (به‌جای ComponentElementPosition)
       Direction-based offsets با CSS position: absolute
    --------------------------------------------- */
    protected renderSelectorPosition(
        attrsDefault?: any,
        data?:         any,
        extra?:        any,
    ): CoreReactive.App {

        const bind = this._COMPONENT_PROPS_BIND;

        const prop_floatDirectionType       = data?.["prop_floatDirectionType"]       ?? bind.prop_floatDirectionType;
        const prop_floatArrowWidth          = data?.["prop_floatArrowWidth"]          ?? bind.prop_floatArrowWidth;
        const prop_floatPosition            = data?.["prop_floatPosition"]            ?? bind.prop_floatPosition;
        const prop_floatShowControlWithSelf = data?.["prop_floatShowControlWithSelf"] ?? bind.prop_floatShowControlWithSelf;
        const prop_floatIsShow              = data?.["prop_floatIsShow"]              ?? bind.prop_floatIsShow;

        return CoreReactive.App.section({
            attrs: {
                ...attrsDefault,
            },
            stylesBind: {
                position:   "absolute",
                display:    this.getStyleDisplay(prop_floatShowControlWithSelf, prop_floatIsShow),
                zIndex:     UtilStyle.Css_ZIndex(UtilConst.ZIndexes.NOTIFY),
                ...this.getStylePositionOffsets(prop_floatDirectionType, prop_floatArrowWidth, prop_floatPosition),
            },
            children: [
                this.executeSchemaPart(Schemas.SELECTOR_POSITION_BORDER.part, {}),
            ],
        });
    }


    /* ---------------------------------------------
       renderSelectorPositionBorder — رندر بخش border
       از ComponentBorder (Category callable) استفاده می‌کند
       Direction-based arrow type mapping
    --------------------------------------------- */
    protected renderSelectorPositionBorder(
        attrsDefault?: any,
        data?:         any,
        extra?:        any,
    ): CoreReactive.App {

        const bind = this._COMPONENT_PROPS_BIND;

        const prop_floatClass         = data?.["prop_floatClass"]         ?? bind.prop_floatClass;
        const prop_floatStyles        = data?.["prop_floatStyles"]        ?? bind.prop_floatStyles;
        const prop_floatContent       = data?.["prop_floatContent"]       ?? bind.prop_floatContent;
        const prop_floatDirectionType = data?.["prop_floatDirectionType"] ?? bind.prop_floatDirectionType;
        const prop_floatArrowWidth    = data?.["prop_floatArrowWidth"]    ?? bind.prop_floatArrowWidth;
        const prop_floatBorderWidth   = data?.["prop_floatBorderWidth"]   ?? bind.prop_floatBorderWidth;
        const prop_floatBorderColor   = data?.["prop_floatBorderColor"]   ?? bind.prop_floatBorderColor;
        const prop_floatBorderRadius  = data?.["prop_floatBorderRadius"]  ?? bind.prop_floatBorderRadius;
        const prop_floatWidth         = data?.["prop_floatWidth"]         ?? bind.prop_floatWidth;
        const prop_floatMinWidth      = data?.["prop_floatMinWidth"]      ?? bind.prop_floatMinWidth;
        const prop_floatArrowPosition = data?.["prop_floatArrowPosition"] ?? bind.prop_floatArrowPosition;
        const prop_floatBackground    = data?.["prop_floatBackground"]    ?? bind.prop_floatBackground;
        const prop_floatColor         = data?.["prop_floatColor"]         ?? bind.prop_floatColor;

        const borderArrowType = this.getBorderArrowType(prop_floatDirectionType);

        const border = UiCategory.UI.Contents.Border(
            {
                classList:  prop_floatClass,
                styles:     prop_floatStyles,

                prop_borderClass:    ["shadow-sm", "position-relative"],
                prop_borderStyles:   this.getStyleBorderPadding(),

                prop_borderArrowType:     borderArrowType,
                prop_borderArrowPosition: prop_floatArrowPosition,
                prop_borderArrowWidth:    prop_floatArrowWidth,
                prop_content:             prop_floatContent,
                prop_borderRadius:        prop_floatBorderRadius,
                prop_borderWidth:         prop_floatBorderWidth,
                prop_width:               prop_floatWidth,
                prop_minWidth:            prop_floatMinWidth,
                prop_contentBackgroundColor: prop_floatBackground,
                prop_borderColor:         prop_floatBorderColor,
                prop_contentColor:        prop_floatColor,
            },
            {},
        );

        return border.getReactiveElement();
    }


    /// ---------------------
    ///  Private Style Getters
    ///  هر متد یک style object یا CoreObservable.App.computed برمی‌گرداند
    ///  توسعه‌پذیر: هر style منطق مستقل دارد
    /// ---------------------

    private getStyleSelector(): Record<string, string> {
        return {
            cursor: "pointer",
        };
    }

    private getStyleDisplay(prop_floatShowControlWithSelf, prop_floatIsShow) {
        return CoreObservable.App.computed(
            (showControlWithSelf, isShow) => {
                if (showControlWithSelf) {
                    return isShow ? "block" : "none";
                }
                return this._IS_SHOW ? "block" : "none";
            },
            [prop_floatShowControlWithSelf, prop_floatIsShow],
            this.getScope(),
        );
    }

    private getStylePositionOffsets(prop_floatDirectionType, prop_floatArrowWidth, prop_floatPosition) {
        return CoreObservable.App.computed(
            (direction, arrowWidth, position, directionRtl) => {
                const offsets: Record<string, string> = {};

                const arrowPx = UtilStyle.Css_SizeUnit(arrowWidth, UtilConst.Units.PEXEL);
                const distancePx = UtilStyle.Css_SizeUnit(10, UtilConst.Units.PEXEL);

                switch (direction) {
                    case DirectionTypes.TOP:
                        offsets.bottom = UtilStyle.Css_SizeCalc(
                            UtilStyle.Css_SizeUnit(100, UtilConst.Units.PERCENT),
                            "+",
                            arrowPx,
                            "-",
                            distancePx,
                        );
                        if (directionRtl) {
                            offsets.right = position
                                ? UtilStyle.Css_SizeUnit(position, UtilConst.Units.PERCENT)
                                : "0";
                        } else {
                            offsets.left = position
                                ? UtilStyle.Css_SizeUnit(position, UtilConst.Units.PERCENT)
                                : "0";
                        }
                        break;

                    case DirectionTypes.BOTTOM:
                        offsets.top = UtilStyle.Css_SizeCalc(
                            arrowPx,
                            "+",
                            UtilStyle.Css_SizeUnit(20, UtilConst.Units.PEXEL),
                        );
                        if (directionRtl) {
                            offsets.right = position
                                ? UtilStyle.Css_SizeUnit(position, UtilConst.Units.PERCENT)
                                : "0";
                        } else {
                            offsets.left = position
                                ? UtilStyle.Css_SizeUnit(position, UtilConst.Units.PERCENT)
                                : "0";
                        }
                        break;

                    case DirectionTypes.LEFT:
                        offsets.right = UtilStyle.Css_SizeCalc(
                            UtilStyle.Css_SizeUnit(100, UtilConst.Units.PERCENT),
                            "+",
                            arrowPx,
                        );
                        offsets.top = position
                            ? UtilStyle.Css_SizeUnit(position, UtilConst.Units.PERCENT)
                            : UtilStyle.Css_SizeUnit(50, UtilConst.Units.PERCENT);
                        offsets.transform = UtilStyle.Css_TranslateUnit(
                            UtilStyle.Css_SizeUnit(0, UtilConst.Units.PERCENT),
                            UtilStyle.Css_SizeUnit(-50, UtilConst.Units.PERCENT),
                        );
                        break;

                    case DirectionTypes.RIGHT:
                        offsets.left = UtilStyle.Css_SizeCalc(
                            UtilStyle.Css_SizeUnit(100, UtilConst.Units.PERCENT),
                            "+",
                            arrowPx,
                        );
                        offsets.top = position
                            ? UtilStyle.Css_SizeUnit(position, UtilConst.Units.PERCENT)
                            : UtilStyle.Css_SizeUnit(50, UtilConst.Units.PERCENT);
                        offsets.transform = UtilStyle.Css_TranslateUnit(
                            UtilStyle.Css_SizeUnit(0, UtilConst.Units.PERCENT),
                            UtilStyle.Css_SizeUnit(-50, UtilConst.Units.PERCENT),
                        );
                        break;
                }

                return offsets;
            },
            [
                prop_floatDirectionType,
                prop_floatArrowWidth,
                prop_floatPosition,
                CoreConfig.Settings.DirectionRtl.observable(),
            ],
            this.getScope(),
        );
    }

    private getStyleBorderPadding() {
        return CoreObservable.App.computed(
            (sizeName) => {
                return {
                    paddingLeft:  UtilStyle.Css_Padding(sizeName),
                    paddingRight: UtilStyle.Css_Padding(sizeName),
                };
            },
            [CoreConfig.Settings.SizeName.observable()],
            this.getScope(),
        );
    }


    /// ---------------------
    ///  Private Logic Methods
    /// ---------------------

    private getBorderArrowType(direction: DirectionTypes): ArrowTypes {
        switch (direction) {
            case DirectionTypes.TOP:    return ArrowTypes.BOTTOM;
            case DirectionTypes.BOTTOM: return ArrowTypes.TOP;
            case DirectionTypes.LEFT:   return ArrowTypes.RIGHT;
            case DirectionTypes.RIGHT:  return ArrowTypes.LEFT;
            default:                    return ArrowTypes.BOTTOM;
        }
    }
}
```

## ۷. ریسک‌ها و ملاحظات

| ریسک | توضیح | راهکار |
|:---|:---|:---|
| **Inline positioning vs ComponentElementPosition** | در legacy از ComponentElementPosition استفاده می‌شد — inline کردن ممکن است رفتار متفاوتی ایجاد کند | تست دقیق positioning در همه ۴ direction (TOP/BOTTOM/LEFT/RIGHT) |
| **`prop_selectorContent` نوع پیچیده** | `string \| CoreReactive.App \| null` — ممکن است circular import ایجاد کند | استفاده از `any` در تعریف prop برای جلوگیری از circular import |
| **`CoreConfig.Settings.DirectionRtl.observable()`** | روش دسترسی به directionRtl observable ممکن است متفاوت باشد | بررسی API از `@/core_configs` قبل از implementation |
| **`UtilStyle.Css_*` functions** | نام‌گذاری توابع utility ممکن است با Plan فرق کند | بررسی دقیق نام توابع از `@/util_styles` قبل از implementation |
| **`ArrowTypes` import از ComponentBorder** | ممکن است circular import ایجاد کند اگر FloatMenu و Border در یک lists index باشند | import مستقیم از `../componentBorder/Props` (نه از index) |
| **Show/hide با `_IS_SHOW` internal state** | در legacy از `_COMPONENT_POSITION.set("prop_show", ...)` استفاده می‌شد — در inline positioning از `prop_floatIsShow` استفاده می‌شود | اطمینان از همگام‌سازی `_IS_SHOW` با `prop_floatIsShow` |
| **`prop_floatShowControlWithSelf`** | این prop کنترل می‌کند چه کسی show/hide را مدیریت می‌کند — در inline positioning باید منطق متفاوتی پیاده‌سازی شود | تست هر دو حالت (true/false) |

## ۸. خلاصه

این پلن مهاجرت `ComponentFloatMenu` از legacy (848 خط، الگوی `GOG_*`) به معماری جدید را تشریح می‌کند. کامپوننت یک **composite component** است که selector + positioning + ComponentBorder را ترکیب می‌کند.

**نکات کلیدی:**
- ۲۰ prop اختصاصی با `Define_ComponentProp<T>(...)` + ۲ enum (DirectionTypes, ShowTypes)
- ۳ schema part با routing در `renderManagerComponent`
- ۰ method (presentational component)
- **Inline positioning** به‌جای وابستگی به ComponentElementPosition — بدون پیش‌نیاز اضافی
- Composition با `UiCategory.UI.Contents.Border` به‌جای `new ComponentBorder(...)`
- ۴ private style getter برای توسعه‌پذیری
- ۱ private logic method (`getBorderArrowType`) برای mapping direction → arrow
- Direction-based positioning (TOP/BOTTOM/LEFT/RIGHT) با RTL support
- Hover/Click show types با `CoreObservable.App.computed`
- ثبت در Category `positions` و ComponentManager

**پیش‌نیاز:** فقط ComponentBorder (مهاجرت شده ✅) — بدون نیاز به ComponentElementPosition (inline positioning انتخاب شده).
