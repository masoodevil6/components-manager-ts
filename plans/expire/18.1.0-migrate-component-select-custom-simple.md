# Plan 18.1.0 — انتقال ComponentSelectCustomSimple به معماری جدید

> وضعیت: اجراشده؛ پیاده‌سازی، ثبت Category/Manager، ترجمه‌ها و تست رفتاری تکمیل شده‌اند.
>
> منبع رفتار: `last/tools/components/simples/ComponentSelectCustomSimple.ts`.
>
> وابستگی‌های قدیمی مرتبط: `ComponentInputSimple`، `ComponentPositionMenu`، `ComponentElementPosition`، `ComponentBorder` و `ComponentRecyclerView` در `last/tools/components`.
>
> راهنمای معماری: `documents/guides/component-create.md`.
>
> مقصد: `src/framework/module_ui/module_components/lists/componentSelectCustomSimple/` و دسترسی `UiCategory.UI.Simples.SelectCustomSimple(config, methods, identity)`.

## ۱. هدف و محدوده

کامپوننت انتخاب سفارشی را از Legacy به ساختار declarative/runtime جدید منتقل کن. انتخاب گزینه، مقدار فرم، جست‌وجو بر اساس نام و پیشوند، نمایش متن انتخاب‌شده، منوی بازشو، حالت disabled، رنگ‌بندی گزینه‌ها، اندازه‌های سیستمی، RTL و callbackهای عمومی باید حفظ شوند.

در runtime جدید از `CoreComponents`، `CoreReactive`، `CoreObservable`، `CoreEvent`، `CoreConfig`، `UtilStyle` و componentهای جدید استفاده کن. import از `last/`، `ReactiveElement`، `Observable`، `ComponentBase`، `TOOLS` و کامپوننت‌های Legacy مجاز نیست.

## ۲. رفتار و API موجود در Legacy

کامپوننت شامل قاب selector و منوی بازشو است. با کلیک قاب در حالت فعال، منو باز یا بسته می‌شود. منو ورودی جست‌وجو و فهرست عمودی گزینه‌ها دارد. جست‌وجو روی `name` و `prefix` انجام می‌شود. انتخاب گزینه `prop_selectValue` را برابر شناسه‌ی گزینه می‌کند و منو را می‌بندد. گزینه‌ی انتخاب‌شده پس‌زمینه‌ی `PRIMARY/GRADE_1` و متن `SHAN/GRADE_1` می‌گیرد؛ گزینه‌های دیگر پس‌زمینه‌ی `SHAN/GRADE_1` و متن `DARK/GRADE_1` دارند. رنگ hover گزینه‌ها `WARNING/GRADE_4` و `WARNING/GRADE_1` است.

در حالت disabled تعامل selector غیرفعال و پس‌زمینه‌ی آن `PRIMARY/GRADE_5` است. input مخفی فرم در Legacy فقط در حالت enabled ساخته می‌شود.

### ۲.۱. Props

| Prop | نوع و پیش‌فرض Legacy | قرارداد مهاجرت |
|:---|:---|:---|
| `prop_selectName` | `string \| null`, پیش‌فرض `null` | نام فیلد hidden input؛ رفتار null را بررسی کن. |
| `prop_selectDisable` | `boolean`, پیش‌فرض `false` | تعامل را غیرفعال و hidden input را مطابق Legacy مدیریت کند. |
| `prop_selectValue` | `string \| null`, پیش‌فرض `null` | شناسه‌ی انتخاب‌شده؛ چون `id` گزینه `string \| number` است، نوع جدید باید `string \| number \| null` را پشتیبانی کند یا تبدیل را مستند کند. |
| `prop_selectClass` | `string[]`, پیش‌فرض `['form-control']` | کلاس‌های اضافی selector؛ محل اعمال روی قاب یا trigger مشخص شود. |
| `prop_selectStyles` | `Record<string, string>`, پیش‌فرض `{}` | استایل‌های اضافی selector با اولویت مشخص. |
| `prop_selectPlaceholder` | `string \| null`, پیش‌فرض `null` | متن جایگزین در نبود مقدار متناظر. |
| `prop_selectOptions` | در نمونه آرایه؛ config فعلی مقدار null دارد | گزینه‌ها به صورت آرایه‌ی `{id: string \| number, name: string \| number, prefix: string \| number}` تعریف شوند؛ فهرست خالی و داده‌ی ناقص امن مدیریت شود. |
| `prop_selectTypeShow` | enum، پیش‌فرض `BOTH` | enum جدید با مقادیر `just_name`, `just_prefix`, `both`. |
| `prop_selectBorderTopLeftRadiusHas` | `boolean`, پیش‌فرض `true` | به prop متناظر `ComponentBorder` نگاشت شود. |
| `prop_selectBorderTopRightRadiusHas` | `boolean`, پیش‌فرض `true` | به prop متناظر `ComponentBorder` نگاشت شود. |
| `prop_selectBorderBottomLeftRadiusHas` | `boolean`, پیش‌فرض `true` | به prop متناظر `ComponentBorder` نگاشت شود. |
| `prop_selectBorderBottomRightRadiusHas` | `boolean`, پیش‌فرض `true` | به prop متناظر `ComponentBorder` نگاشت شود. |
| `prop_selectBorderTopHas` | `boolean`, پیش‌فرض `true` | به prop متناظر `ComponentBorder` نگاشت شود. |
| `prop_selectBorderRightHas` | `boolean`, پیش‌فرض `true` | به prop متناظر `ComponentBorder` نگاشت شود. |
| `prop_selectBorderBottomHas` | `boolean`, پیش‌فرض `true` | به prop متناظر `ComponentBorder` نگاشت شود. |
| `prop_selectBorderLeftHas` | `boolean`, پیش‌فرض `true` | به prop متناظر `ComponentBorder` نگاشت شود. |

Props پایه از `ComponentStructureTrait` به ارث برسند و دوباره تعریف نشوند. propهای اختصاصی با `Define_ComponentProp<T>`، metadata ترجمه‌شده از `Keys` و typeهای `ExtractPropsType` و `ExtractPropsConfigType` ساخته شوند؛ nullable بودن نوع‌ها صریح باشد.

### ۲.۲. Methods

| Method پیشنهادی | نام Legacy | قرارداد پیشنهادی |
|:---|:---|:---|
| `SELECT_CHANGE` | `fn_onSelectChange` | پس از انتخاب گزینه؛ `VALUE` شناسه‌ی گزینه‌ی جدید و event کلیک. |
| `SELECT_SEARCH` | `fn_onSelectSearch` | هنگام تغییر query؛ `VALUE` متن جست‌وجو و event input. |
| `SELECT_OPEN` | `fn_onSelectOpen` | هنگام بازشدن؛ `VALUE` شناسه‌ی انتخاب فعلی و event محرک. |
| `SELECT_CLOSE` | `fn_onSelectClose` | هنگام بسته‌شدن؛ `VALUE` شناسه‌ی انتخاب فعلی و event محرک. |

در Legacy همه‌ی callbackها dataArg با نام `value` داشتند و مقدار selected را می‌گرفتند. معنای تغییر‌یافته‌ی `SELECT_SEARCH` باید در metadata و مثال ثبت شود. همه‌ی callbackها از `executeMethod` اجرا شوند.

## ۳. Schemas و درخت DOM

`COMPONENT` و `STRUCTURE` از `ComponentStructureTrait.schemas` به ابتدای Schemas افزوده شوند. schemaهای اختصاصی پیشنهادی:

| Schema | part پیشنهادی | نقش |
|:---|:---|:---|
| `FORM` | `part-select-custom-simple-form` | ریشه‌ی محتوای کامپوننت. |
| `FORM_VALUE` | `part-select-custom-simple-value` | hidden input فرم برای name و value. |
| `SELECT` | `part-select-custom-simple-select` | اتصال trigger به منوی انتخاب. |
| `SELECT_HEADER` | `part-select-custom-simple-header` | قاب Border، متن و آیکون باز/بسته. |
| `SELECT_HEADER_TEXT` | `part-select-custom-simple-header-text` | مقدار انتخاب‌شده یا placeholder طبق enum نمایش. |
| `SELECT_HEADER_ICON` | `part-select-custom-simple-header-icon` | آیکون متناسب با وضعیت منو. |
| `SELECT_BODY` | `part-select-custom-simple-body` | بدنه‌ی منو شامل جست‌وجو و فهرست. |
| `SELECT_SEARCH` | `part-select-custom-simple-search` | ورودی جست‌وجو؛ از `ComponentInputSimple` جدید استفاده شود. |
| `SELECT_OPTIONS` | `part-select-custom-simple-options` | فهرست عمودی و فیلترشده‌ی گزینه‌ها. |
| `SELECT_OPTION` | `part-select-custom-simple-option` | رندر و انتخاب یک گزینه با context گزینه. |

Schema فقط تعریف part و props را نگه دارد؛ rendererها در `ComponentSelectCustomSimple.ts` باشند. از API جدید `ComponentBorder`، `ComponentIcon`، `ComponentInputSimple`، `ComponentRecyclerView` و `ComponentPositionMenu` یا `ComponentFloatMenu` استفاده شود. پیش از انتخاب منو، API جدید و رفتار outside click/stacking آن بررسی شود؛ positioning دستی یا import از Legacy به کار نرود.

## ۴. رفتار، اندازه و تعامل

- ابعاد selector از `CoreConfig.Settings.SizeName` و `UtilStyle` محاسبه شوند؛ اندازه‌ی ثابت و `prop_size` جدید اضافه نشود.
- جهت متن از `CoreConfig.Settings.DirectionRtl` گرفته شود. چیدمان name/prefix/separator در RTL و LTR کار کند و به `float: left` وابسته نباشد.
- رنگ قاب حالت عادی `PRIMARY/GRADE_1`، حالت باز `SECONDARY/GRADE_1` و وضعیت hover/disabled مستقل باشد.
- تغییر آیکون با state واقعی منو هماهنگ باشد و کلیک آن باعث toggle دوباره نشود.
- جست‌وجو روی name و prefix، با تبدیل ایمن مقادیر string/number به متن انجام شود. تغییر options باید فهرست را واکنشی تازه کند.
- انتخاب گزینه، مقدار component، متن header و hidden input را همگام کند؛ منو بسته و `SELECT_CHANGE` فقط یک بار اجرا شود.
- قرارداد outside click، Escape، focus/blur، فهرست خالی و انتخاب ناموجود در مرحله‌ی پیاده‌سازی تعیین و آزمایش شود.
- `dispose()` listenerها، child componentها، Stepها و observableهای متعلق به همین instance را آزاد کند.

- وابستگی‌های Legacy به `ComponentBorder`، `ComponentPositionMenu`، `ComponentElementPosition`، `ComponentIcon` و `ComponentRecyclerView` با نسخه‌های جدید جایگزین شوند.
- implementation جدید هیچ import runtime از `last/` یا `tools/components` نداشته باشد.

## ۹. ریسک‌ها و تصمیم‌های زمان اجرا

تصمیم‌های اجراشده:

1. `prop_selectValue` مقدار `string | number | null` را نگه می‌دارد؛ hidden input مقدار را به string تبدیل می‌کند و ID اصلی در state دست‌نخورده می‌ماند.
2. `SELECT_SEARCH` متن query را در `componentArgs.VALUE` می‌فرستد؛ `SELECT_OPEN` و `SELECT_CLOSE` مقدار انتخاب‌شده را می‌فرستند.
3. منو با `ComponentFloatMenu` جدید کنترل می‌شود؛ trigger کلیکی است و کلیک بیرون و Escape منو را می‌بندند.
4. hidden input در حالت disabled حذف می‌شود تا رفتار فرم Legacy حفظ شود.
5. lookup انتخاب‌شده با `String(id)` انجام می‌شود تا IDهای عددی و رشته‌ای هم‌ارز نمایش داده شوند؛ مقدار ذخیره‌شده‌ی گزینه تغییر نمی‌کند.
6. `name` و `prefix` فقط هنگام نمایش و جست‌وجو به متن تبدیل می‌شوند.

تست‌های رفتاری `tests/perf/select-custom-simple.test.ts` مسیر جست‌وجو، انتخاب، disabled، Escape و کلیک بیرون را بررسی می‌کنند.
