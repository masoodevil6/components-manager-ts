> **وضعیت:** پیاده‌سازی شد؛ بررسی نهایی انجام شد

> **منبع Legacy:** last/tools/components/ComponentInputColor.ts

## 1. هدف و محدوده

انتقال انتخابگر رنگ قدیمی به معماری declarative/runtime جدید و حفظ قراردادهای قابل استفادهٔ آن: label، نمایش swatch، پاک‌کردن رنگ، باز و بسته‌شدن picker، انتخاب با سطح saturation/lightness و hue، opacity، نمایش و کپی hex، اعتبارسنجی و رویداد CHANGE.

نسخهٔ Legacy همهٔ این بخش‌ها را به رابط اصلی متصل نکرده است: Main فقط schema انتخابگر را فراخوانی می‌کند، FormColorSelector یک ComponentPositionMenu آزمایشی با متن «asd» می‌سازد و رندر چند بخش اصلی در Main کامنت است. در مهاجرت، منطق و قراردادهای قابل استفاده مبنا باشند؛ placeholder آزمایشی رفتار نهایی محسوب نشود.

## 3. قرارداد props و تبدیل Legacy

- Props مشترک component و structure از ComponentStructureTrait و props مربوط به label از ComponentLabelTrait گرفته شوند؛ دوباره تعریف نشوند.
- prop_size قدیمی به API جدید منتقل نشود. اندازه‌های وابسته به سیستم از CoreConfig.Settings.SizeName و UtilStyle گرفته شوند.
- var_isEmptyColor، hue، saturation، lightness، opacity، وضعیت popup و drag، state داخلی باشند و به‌عنوان prop عمومی ثبت نشوند.
- پیش از حذف یا تغییر نام props، کل repository با rg برای مصرف‌کننده‌های Legacy جست‌وجو شود.
- Props جدید با Define_ComponentProp<T>، Keys ترجمه، satisfies CoreComponents.ComponentProps و type helperهای راهنما تعریف شوند.

| Legacy | تصمیم مهاجرت |
|---|---|
| prop_value و prop_colorSelected | یک منبع حقیقت controlled برای رنگ داشته باشند. prop_colorSelected در صورت مصرف واقعی Legacy به‌عنوان alias همگام حفظ شود. |
| prop_showTitleFront | حفظ؛ نمایش مقدار hex کنار swatch را کنترل کند. |
| prop_borderColor | حفظ؛ فقط برای border swatch باشد. |
| prop_formClass و prop_formStyles | customization فرم/swatch حفظ شود و با styleهای پایه merge شود. |
| prop_optionWidth و prop_optionHeight | ابعاد سفارشی popup حفظ شوند؛ defaultهای Legacy برابر 350 و 375 پیکسل‌اند. |
| prop_optionStyles | حفظ و فقط به پوستهٔ popup اعمال شود؛ استایل ضروری داخلی picker نباید ناخواسته بازنویسی شود. |
| prop_positionTop | کاربرد Legacy ناقص/نامتصل است؛ نگاشت به API FloatMenu بررسی شود و در صورت نبود نگاشت، حذف/deprecated مستند شود. |
| prop_backgroundColorBody و prop_colorBody | حفظ و به زمینهٔ popup و رنگ متن اطلاعات پایین picker نگاشت شوند. |
| prop_colorIconClear و prop_colorIconEmpty | حفظ؛ رنگ آیکون‌های clear و empty از مسیر رنگ استاندارد آیکون تنظیم شود. |
| prop_hasRules، prop_isAbsoluteRule، prop_listRules، prop_msgRules | حفظ و به ComponentValidate نگاشت شوند؛ در disabled یا نبود rules معتبر، validator نمایش داده نشود. |

prop_value مقدار اصلی canonical به شکل hex، مانند #ff0000، نگهداری کند؛ clear مقدار خالی "" قرار دهد. CHANGE مقدار hex یا رشتهٔ خالی را ارسال کند. مقدار controlled بیرونی نباید در هر render یا init بی‌دلیل overwrite شود.

در Legacy opacity روی preview اثر دارد، اما callback مقدار hex بدون alpha می‌فرستد. همین قرارداد حفظ شود مگر مصرف‌کننده‌ای خلاف آن را اثبات کند و تغییر API جداگانه تصویب شود؛ prop_value نباید گاهی HSL یا RGBA بگیرد. درصد opacity از state opacity مشتق شود.

## 5. رفتار و state

- مقدار شروع از controlled value جاری خوانده شود؛ ورودی خالی/نامعتبر نباید crash کند یا مقدار بیرونی را خودکار تغییر دهد.
- تبدیل hex/HSL/RGB و محاسبهٔ RGBA از منطق Legacy استخراج و ورودی hex سه‌رقمی/شش‌رقمی و مقدار ناقص ایمن مدیریت شود.
- drag در SL، hue و opacity تا mouseup کار کند؛ مختصات clamp شوند و نشانگر/preview پیوسته به‌روز شوند.
- تغییر hue گرادیان SL و opacity را redraw کند؛ تغییر SL رنگ preview و hex را عوض کند؛ تغییر opacity preview و درصد را به‌روز کند.
- پس از بازشدن popup، canvasها بعد از mount و اندازه‌گیری ابعاد معتبر redraw شوند.
- clear مقدار را "" کند، حالت خالی را فعال و یک CHANGE با مقدار خالی بفرستد. در disabled clear قابل اجرا نباشد.
- کلیک روی hex با navigator.clipboard?.writeText انجام شود؛ نبود Clipboard API خطا ایجاد نکند.
- کلیک بیرون popup آن را ببندد، اما کلیک درون popup یا swatch باعث بسته‌شدن ناخواسته نشود.
- listenerهای window/document برای هر instance فقط یک‌بار نصب شوند و در dispose حذف شوند؛ setup نباید با renderهای متعدد listener تکراری بسازد.
- اگر disabled هنگام بازبودن picker فعال شد، picker بسته شود و click/drag/clear/copy تغییری در state یا callback نسازند.
- وضعیت و جهت popup، محل clear و نشانگرها در LTR و RTL بررسی شود.

## 6. Methods

Legacy یک CHANGE دارد:

| Method | Data args | قرارداد |
|---|---|---|
| CHANGE | COLOR: string | بعد از انتخاب رنگ معنی‌دار یا clear، دقیقاً یک‌بار با hex canonical یا رشتهٔ خالی اجرا شود. |

Methods.ts جدید مطابق convention پروژه و ExtractMethods* باشد. رویداد اضافه برای حرکت drag تعریف نشود؛ تغییر داخلی opacity یا کپی/بازوبسته‌شدن picker نباید CHANGE رنگ تکراری تولید کند.
