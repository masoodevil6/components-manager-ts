# Plan 5.9 — افزودن Generic Parameter برای Identity (unique + emit + events) به ComponentStructure

## هدف

افزودن یک Generic Parameter چهارم به `ComponentStructure` برای type-safety کامل `unique`، `emit` و `events`.

این سه پارامتر همگی مربوط به **Runtime Identity** یک Component Instance هستند:
- `unique: CoreEvent.TStepRef | null` — هویت یکتای Instance در درخت Workflow
- `emit: CoreEvent.TEmitHandler | null` — Request Handler متصل به المان
- `events: Record<string, any> | null` — Event handlerهای متصل به Component

---

## وضعیت فعلی

### ClComponentBase (Core)

```ts
class ClComponentBase<TProp, TSchemas, _, TMethods> {

    _COMPONENT_UNIQUE: CoreEvent.TStepRef | null = null;
    _COMPONENT_EMIT:   CoreEvent.TEmitHandler | null = null;

    constructor(componentName: string, elId: string | null) { ... }

    renderComponent(
        config: TProp,
        methods: TMethods,
        events = null,
        unique: CoreEvent.TStepRef | null = null,
        emit:   CoreEvent.TEmitHandler | null = null
    ) {
        this._COMPONENT_UNIQUE = unique;
        this._COMPONENT_EMIT = emit;
        ...
    }
}
```

### ComponentStructure (UI)

```ts
class ComponentStructure<
    TProp extends Record<string, any> = PropsType,
    TSchemas = SchemasType,
    TMethods extends Record<string, any> = MethodsType
> extends CoreComponents.App<TProp, TSchemas, any, TMethods> {

    constructor(componentName: string = "structure", elId: string | null = null) {
        super(componentName, elId);
    }
}
```

### مشکلات وضعیت فعلی

1. `unique`، `emit` و `events` در `renderComponent` پاس می‌شوند، نه در constructor — یعنی Component قبل از `renderComponent` هویت ندارد.
2. هیچ type-safety ای روی `unique`، `emit` و `events` وجود ندارد — همیشه `any` یا `null` هستند.
3. `ExampleRenderer` مجبور است `unique`، `emit` و `events` را به constructor پاس دهد، ولی `ComponentStructure` constructor آن‌ها را نمی‌گیرد.
4. فرزندها (مثل ComponentButton آینده) باید بتوانند type اختصاصی `events` داشته باشند.

## معماری هدف

### Type جدید: `ComponentIdentity`

```ts
import * as CoreEvent from "@/core_event";

/**
 * Identity یک Component Instance
 *
 * شامل سه فیلد مربوط به Runtime Identity:
 *   unique — هویت یکتای Instance در درخت Workflow (CoreEvent.TStepRef)
 *   emit   — Request Handler متصل به المان (CoreEvent.TEmitHandler)
 *   events — Event handlerهای متصل به Component
 *
 * این Type به‌عنوان Generic Parameter چهارم ComponentStructure استفاده می‌شود.
 * فرزندها می‌توانند type اختصاصی داشته باشند (مثلاً ButtonIdentity).
 */
export interface ComponentIdentity {
    unique: CoreEvent.TStepRef | null;
    emit:   CoreEvent.TEmitHandler | null;
    events: Record<string, any> | null;
}
```

### ComponentStructure با ۴ Generic Parameter

```ts
class ComponentStructure<
    TProp extends Record<string, any> = PropsType,
    TSchemas = SchemasType,
    TMethods extends Record<string, any> = MethodsType,
    TIdentity extends ComponentIdentity = ComponentIdentity
> extends CoreComponents.App<TProp, TSchemas, any, TMethods> {

    constructor(
        componentName: string = "structure",
        elId: string | null = null,
        identity?: Partial<TIdentity>,
    ) {
        super(componentName, elId);

        this._COMPONENT_UNIQUE = identity?.unique ?? null;
        this._COMPONENT_EMIT   = identity?.emit ?? null;
        this._COMPONENT_EVENTS = identity?.events ?? null;
    }
}
```

### ExampleRenderer

```ts
const component = new ComponentConstructor(
    example.config,
    example.methods ?? {},
    {
        unique:  example.unique ?? null,
        emit:    example.emit ?? null,
        events:  example.events ?? null,
    },
);

return component.getElement();
```

## نکات مهم

### چرا `Partial<TIdentity>` در constructor؟

چون Component ممکن است بدون identity ساخته شود (مثلاً Example بدون Workflow).
`Partial` اجازه می‌دهد یکی از سه فیلد یا هیچکدام پاس داده شود.

### چرا Generic Parameter جداگانه؟

چون فرزندها می‌توانند type اختصاصی داشته باشند:

```ts
interface ButtonIdentity extends ComponentIdentity {
    unique:  ButtonStepRef | null;       // خاص Button
    events:  ButtonEventHandlers | null; // خاص Button
}

class ComponentButton extends ComponentStructure<
    ButtonPropsType,
    ButtonSchemasType,
    ButtonMethodsType,
    ButtonIdentity
> { ... }
```

### سازگاری با Core

`ClComponentBase` تغییر نمی‌کند — `_COMPONENT_UNIQUE` و `_COMPONENT_EMIT` همچنان public هستند.
`ComponentStructure` فقط در constructor آن‌ها را set می‌کند (به‌جای `renderComponent`).

### سازگاری با renderComponent

`renderComponent` همچنان `events`، `unique` و `emit` را می‌گیرد و set می‌کند.
اگر constructor آن‌ها را set کرده باشد، `renderComponent` override می‌کند.
این backward compatibility را حفظ می‌کند.
