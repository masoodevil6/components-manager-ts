# Plan 8.1.1 — اصلاح معماری ComponentIcon

## مشکل

در پلن ۸.۱، `ComponentIcon` از `ComponentStructure` ارث بری کرد. این اشتباه است:

```
ComponentStructure  ←  ComponentIconBase  ←  ComponentIcon
```

این یعنی ComponentIcon **IS-A** ComponentStructure — ولی باید **HAS-A** ComponentStructure باشد.

## معماری درست

```
ClComponentBase (CoreComponent)
  ├── ComponentStructure  (خودش یک Component مستقل)
  └── ComponentIcon        (خودش یک Component مستقل)
        └── internally USES ComponentStructure
```

### ۴ اصلاح

#### ۱) Examples — استفاده از کلید ترجمه

**مشکل:** `name` و `description` در Exampleها خام نوشته شده:
```typescript
name:        "Default Icon",           // ❌ خام
description: "Basic icon display",     // ❌ خام
```

**راه‌حل:** از `Keys` استفاده شود:
```typescript
name:        Keys.category.components.icon.examples.default.name,
description: Keys.category.components.icon.examples.default.description,
```

نیاز به به‌روزرسانی `Keys.ts` و `ComponentExampleDefinition` interface.

#### ۲) ارث بری از CoreComponent نه ComponentStructure

**مشکل:**
```typescript
class ComponentIconBase extends ComponentStructure<...>  // ❌
```

**راه‌حل:**
```typescript
class ComponentIconBase extends CoreComponents.App<...>  // ✅ ClComponentBase
```

#### ۳) ComponentStructure به‌عنوان اولین فرزند

**مشکل:** ComponentIcon خودش ComponentStructure است — content در `renderContentComponent` مستقیم رندر می‌شود.

**راه‌حل:** ComponentIcon یک ComponentStructure می‌سازد و content خود را در `content` آن قرار می‌دهد:

```typescript
class ComponentIcon extends ComponentIconBase {

    override renderContentComponent(): CoreReactive.App {
        // ساخت ComponentStructure با content = renderIcon
        return ComponentStructure.create({
            classList:           this.getProp("classList"),
            prop_show:           this.getProp("prop_show"),
            prop_structureClass: this.getProp("prop_structureClass"),
            prop_structureStyles:this.getProp("prop_structureStyles"),
            content: () => this.renderIcon(),
        });
    }
}
```

#### ۴) اشتراک propهای ComponentStructure

**مشکل:** ComponentIcon فقط propهای اختصاصی خود را دارد (`prop_icon`, `prop_iconTitle`, ...). کاربر نمی‌تواند `prop_show` یا `classList` را set کند.

**راه‌حل:** ComponentIcon propهای ComponentStructure را هم در `_COMPONENT_PATTERN` خود ثبت می‌کند — ولی فقط برای forward کردن به ComponentStructure:

```typescript
class ComponentIconBase extends CoreComponents.App<...> {

    protected _COMPONENT_PATTERN = CoreComponents.DefineProp({
        ...ComponentStructureProps,   // ۷ prop پایه (forward می‌شوند)
        ...Props,                     // ۴ prop اختصاصی
    } as any);
}
```

این یعنی کاربر می‌نویسد:
```typescript
new ComponentIcon({
    prop_show:    false,           // ✅ از ComponentStructure
    classList:    ["p-3", "border"], // ✅ از ComponentStructure
    prop_icon:    myIcon,          // ✅ اختصاصی ComponentIcon
    prop_iconTitle: "Arrow",       // ✅ اختصاصی ComponentIcon
}, { ... })
```

و ComponentIcon در `renderContentComponent` این propهای پایه را به ComponentStructure پاس می‌دهد.

## تغییرات جزئی

### ComponentIconBase.ts

```typescript
import * as CoreComponents   from "@/core_components";
// --------------------------------
import {Props as StructureProps} from "../componentStructure/Props";
// --------------------------------
import {Props,     PropsType}     from "./Props";
import {Schemas,   SchemasType}   from "./Schemas";
import {Methods,   MethodsType}   from "./Methods";
import {Definition}               from "./Definition";


export class ComponentIconBase extends CoreComponents.App<
    PropsType,
    SchemasType,
    any,
    MethodsType
> {

    protected _COMPONENT_DEFINITION = Definition;

    // ۷ prop پایه + ۴ prop اختصاصی
    protected _COMPONENT_PATTERN = CoreComponents.DefineProp<PropsType & Record<string, any>>({
        ...StructureProps,   // forward می‌شوند به ComponentStructure
        ...Props,            // اختصاصی ComponentIcon
    } as any);

    protected _COMPONENT_SCHEMA = CoreComponents.DefineSchema<SchemasType, PropsType>({
        ...Schemas,
    } as any);

    protected _COMPONENT_METHODS = CoreComponents.DefineMethod<MethodsType, PropsType>({
        ...Methods,
    } as any);

}
```

### ComponentIcon.ts

```typescript
import * as CoreReactive   from "@/core_reactive";
import * as CoreObservable from "@/core_observable";
// --------------------------------
import {ComponentIconBase}  from "./ComponentIconBase";
import {IconStep}           from "./Step";
import {Schemas}            from "./Schemas";
import {Props}              from "./Props";
import {MethodsType}        from "./Methods";
import {ComponentIdentity}  from "@/core_components";
import {PartAttrDefault}    from "@/core_components";
import {ComponentStructure} from "../componentStructure/ComponentStructure";


export class ComponentIcon extends ComponentIconBase {

    constructor(
        config:  Record<string, any>,
        methods: Record<string, any>,
        identity?: Partial<ComponentIdentity>,
    ) {
        super("icon", null);
        this._COMPONENT_UNIQUE = identity?.unique ?? null;
        this._COMPONENT_EMIT   = identity?.emit ?? null;
        this._COMPONENT_EVENTS = identity?.events ?? null;
        this.renderComponent(config as any, methods as any, identity?.events ?? null);
    }


    /* ---------------------------------------------
       renderContentComponent — ساخت ComponentStructure
       با content = renderIcon
    --------------------------------------------- */
    override renderContentComponent(): CoreReactive.App {

        // خواندن propهای پایه از _COMPONENT_PROPS_BIND
        const classList            = this._COMPONENT_PROPS_BIND["classList"];
        const styles               = this._COMPONENT_PROPS_BIND["styles"];
        const prop_show            = this._COMPONENT_PROPS_BIND["prop_show"];
        const prop_structureClass  = this._COMPONENT_PROPS_BIND["prop_structureClass"];
        const prop_structureStyles = this._COMPONENT_PROPS_BIND["prop_structureStyles"];

        // ساخت ComponentStructure با content = renderIcon
        const structEl = ComponentStructure.create({
            classList:              classList?.get() ?? [],
            styles:                 styles?.get() ?? {},
            prop_show:              prop_show?.get() ?? true,
            prop_structureClass:    prop_structureClass?.get() ?? [],
            prop_structureStyles:   prop_structureStyles?.get() ?? {},
            content: () => this.renderIcon(),
        });

        // تبدیل HTMLElement به CoreReactive.App
        return CoreReactive.App.part("section", {
            children: [structEl],
        });
    }


    /* ---------------------------------------------
       renderManagerComponent — Routing
    --------------------------------------------- */
    override renderManagerComponent(
        partName:     string,
        attrsDefault: PartAttrDefault,
        data:         Record<string, CoreObservable.App<any>>,
        extra:        any,
    ): CoreReactive.App {

        switch (partName) {
            case Schemas.ICON.part:
                return this.renderIcon(attrsDefault, data);
            default:
                return super.renderManagerComponent(partName, attrsDefault, data, extra);
        }
    }


    /* ---------------------------------------------
       renderIcon — رندر Part ICON
    --------------------------------------------- */
    protected renderIcon(
        attrsDefault?: PartAttrDefault,
        data?:         Record<string, CoreObservable.App<any>>,
    ): CoreReactive.App {

        const prop_icon       = data?.["prop_icon"]       ?? this._COMPONENT_PROPS_BIND.prop_icon;
        const prop_iconTitle  = data?.["prop_iconTitle"]  ?? this._COMPONENT_PROPS_BIND.prop_iconTitle;
        const prop_iconClass  = data?.["prop_iconClass"]  ?? this._COMPONENT_PROPS_BIND.prop_iconClass;
        const prop_iconStyles = data?.["prop_iconStyles"] ?? this._COMPONENT_PROPS_BIND.prop_iconStyles;

        return CoreReactive.App.i({
            attrs: {
                ...attrsDefault,
            },
            attrsBind: {
                title: prop_iconTitle,
            },
            stylesBind: prop_iconStyles,
            classBind: [
                prop_iconClass,
            ],
            on: {
                click: (event: Event) => {
                    event.preventDefault();
                    this.executeMethod("CLICK", event, {});
                },
                mouseenter: (event: Event) => {
                    event.preventDefault();
                    this.executeMethod("HOVER", event, {});
                },
                mouseleave: (event: Event) => {
                    event.preventDefault();
                    this.executeMethod("BLUR", event, {});
                },
            },
            children: [
                prop_icon,
            ],
        });
    }

}
```

## نکات مهم

### چرا composition نه inheritance؟

| Inheritance | Composition |
|:---|:---|
| ComponentIcon IS-A ComponentStructure | ComponentIcon HAS-A ComponentStructure |
| ComponentIcon به internals ComponentStructure دسترسی دارد | ComponentIcon فقط API public ComponentStructure را استفاده می‌کند |
| ComponentStructure تغییر کند، ComponentIcon خراب می‌شود | ComponentStructure تغییر کند، ComponentIcon تأثیر نمی‌گیرد |
| سلسله مراتب مسطح — همه فرزند ComponentStructure | سلسله مراتب واقعی — هر Component مستقل |

### forward کردن propها

ComponentIcon propهای پایه (`classList`, `prop_show`, ...) را در `_COMPONENT_PATTERN` ثبت می‌کند — این یعنی:
1. کاربر می‌تواند آن‌ها را set کند
2. `renderComponent` آن‌ها را در `_COMPONENT_PROPS_BIND` قرار می‌دهد
3. `renderContentComponent` آن‌ها را از `_COMPONENT_PROPS_BIND` می‌خواند و به `ComponentStructure.create()` پاس می‌دهد

### ComponentStructure.create() خروجی HTMLElement

`ComponentStructure.create()` خروجی `HTMLElement` می‌دهد — ولی `renderContentComponent` باید `CoreReactive.App` برگرداند. راه‌حل: wrap در `CoreReactive.App.part("section", { children: [structEl] })`.
