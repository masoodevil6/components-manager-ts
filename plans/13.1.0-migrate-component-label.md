> **پیش‌نیاز:** Plan 10.1 (ComponentBorder Migration — انجام شده), Plan 11.2 (Structure-First Schema), Plan 9.1.3 (Define_ComponentProp), Plan 8.2.7 (SubEvent)

### ۱.۲. مقایسه Propها (Legacy ۱۵ — همه بازیابی)

| Prop قدیمی | نوع قدیمی | Default قدیمی | نوع جدید | Default جدید |
|:---|:---|:---|:---|:---|
| `prop_labelShow` | `boolean` | `true` | `boolean` | `true` |
| `prop_labelBackground` | `Color(PRIMARY, GRADE_1)` | رنگ | `string \| null` | `UtilStyle.Css_Color(UtilConst.ColorMain.PRIMARY, UtilConst.ColorGrad.GRADE_1)` |
| `prop_labelRadius` | `SIZES.M` | M | `UtilConst.Sizes` | `UtilConst.Sizes.M` |
| `prop_labelMinWidth` | `SizeUnit \| CalcSizeUnit \| null` | `null` | `string \| null` | `null` |
| `prop_labelTitle` | `string \| null` | `null` | `string \| null` | `null` |
| `prop_labelFor` | `string \| null` | `null` | `string \| null` | `null` |
| `prop_labelStyle` | `Record<string,string>` | `{}` | `Record<string,string>` | `{}` |
| `prop_labelClass` | `string[]` | `[]` | `string[]` | `[]` |
| `prop_labelColor` | `Color(SHAN, GRADE_1)` | رنگ | `string \| null` | `UtilStyle.Css_Color(UtilConst.ColorMain.SHAN, UtilConst.ColorGrad.GRADE_1)` |
| `prop_labelTooltipIcon` | `IconsType` (`icon_exclamation_square`) | آیکون | `UiIcons.IIconDefinition \| null` | معادل `UiIcons.Src` — فاز ۰ تأیید شود |
| `prop_labelTooltipDescription` | `string \| null` | `null` | `string \| null` | `null` |
| `prop_labelTooltipBackground` | `Color(SECONDARY, GRADE_1)` | رنگ | `string \| null` | `UtilStyle.Css_Color(SECONDARY, GRADE_1)` |
| `prop_labelTooltipColor` | `Color(SECONDARY, GRADE_1)` | رنگ | `string \| null` | `UtilStyle.Css_Color(SECONDARY, GRADE_1)` |
| `prop_labelTooltipPosition` | `SizeUnit(2.5, PERCENT)` | آفست عمودی آیکون | `string` | `UtilStyle.Css_SizeUnit(2.5, UtilConst.Units.PERCENT)` |
| `prop_labelTooltipDirection` | `ComponentLabel_TooltipPositionTypes.BOTTOM` | BOTTOM | `TooltipDirectionTypes` (enum جدید محلی) | `TooltipDirectionTypes.BOTTOM` |

**تغییرات نسبت به Legacy:**
- رنگ‌ها به `string` (خروجی `Css_Color` — سازگار با CSS vars)
- `IconsType` (widget instance) → `UiIcons.IIconDefinition` (data-only descriptor) — مطابق اصل «Props فقط Metadata»
- نام enum `ComponentLabel_TooltipPositionTypes` (مضرس — در واقع direction بود) → `TooltipDirectionTypes` (اصلاح نام‌گذاری)
- `prop_labelShow` حفظ می‌شود — رندر شرطی با `conditionWhen`

### ۱.۳. وابستگی‌ها و تصمیم Tooltip

| وابستگی | وضعیت در معماری جدید | تصمیم |
|:---|:---|:---|
| `ComponentBorder` | ✅ مهاجرت‌شده — `componentBorder/` | Composition با `UiCategory.UI.Simples.Border` (فاز ۰ امضا تأیید شود) |
| `ComponentTooltipDescription` | ❌ مهاجرت نشده | **راه‌حل این پلن: Tooltip داخلی مینیمال (inline)** — بدون وابستگی به کامپوننت مهاجرت‌نشده |

**تصمیم معماری Tooltip:** Legacy در `templateFn_render_borderContentTooltip` فقط یک wrapper می‌ساخت: آیکون (`prop_labelTooltipIcon`) + popup توضیحات (`ComponentTooltipDescription`). در این پلن، همان Behavior با پیاده‌سازی داخلی بازسازی می‌شود:

```
section.position-relative (part-label-content)
   └── children: [TITLE part, TOOLTIP part]
TOOLTIP part (رندر شرطی — فقط اگر Description != null):
   └── span (آیکون، position: absolute، top از prop_labelTooltipPosition)
        └── CSS :hover → نمایش popup توضیحات (بدون JS)
```

- نمایش/مخفی‌سازی popup با CSS (`opacity` + `visibility` + `:hover` یا کلاس `show`) — بدون state JS (ساده‌تر و بدون listener leak)
- اگر در آینده `ComponentTooltipDescription` مهاجرت داده شود، فقط `renderLabelTooltip` override/replaced می‌شود — بقیه component دست‌نخورده

### ۱.۴. مقایسه Schemaها (Legacy ۴ ← جدید ۵ با Structure-First)

| Schema جدید | part | معادل Legacy | props |
|:---|:---|:---|:---|
| `COMPONENT` (از Trait) | لایه component | — | Plan 11.2 |
| `STRUCTURE` (از Trait) | لایه structure | — | Plan 11.2 |
| `BORDER` | `part-label-border` | `part-border` | Background, Radius, MinWidth |
| `BORDER_CONTENT` | `part-label-content` | `part-content` | (فقط container) |
| `BORDER_CONTENT_TITLE` | `part-label-content-title` | `part-content-label` | Title, For, Style, Class, Color |
| `BORDER_CONTENT_TOOLTIP` | `part-label-content-tooltip` | `part-content-tooltip` | هر ۶ prop tooltip |

**تغییر نام:** `BORDER_CONTENT_LABEL` → `BORDER_CONTENT_TITLE` (محتوای آن title است — وضوح بهتر؛ schema key قدیمی گمراه‌کننده بود چون خود Label بودیم).

**نقشه‌ی `part-label` پایه (Legacy):** part ریشه `part-label` در Legacy (که با `checkExecutePart` بررسی می‌شد) به لایه‌های `COMPONENT` + `STRUCTURE` (Trait — Plan 11.2) منتقل می‌شود؛ یعنی رندر ریشه‌ی خود کامپوننت (`renderContentComponent`) جایگزین آن است — schema جدیدی برای آن ساخته نمی‌شود.

### فاز ۸ — `ComponentLabel.ts` (Rendering)

```
renderContentComponent()                      ← Trait (Plan 11.2)
   └── renderLabelBorder()                    ← Part BORDER
         └── UiCategory.UI.Simples.Border(    ← Composition (مهاجرت‌شده)
               prop_contentBackgroundColor = prop_labelBackground,
               prop_borderRadius          = prop_labelRadius,
               prop_minWidth              = prop_labelMinWidth,
               prop_borderClass           = ["position-relative", "py-0", "px-2"],

```

| متد | part | Behavior بازیابی‌شده از Legacy |
|:---|:---|:---|
| `renderContentComponent()` | — | `executeSchemaPart(BORDER)` — با شرط `prop_labelShow` (`conditionWhen`) |
| `renderLabelBorder()` | BORDER | Border composition + click → CLICK method |
| `renderLabelContent()` | BORDER_CONTENT | `section.position-relative` + `cursor: pointer` + children [TITLE, TOOLTIP] |
| `renderLabelTitle()` | BORDER_CONTENT_TITLE | `section` با `attrsBind: {for: prop_labelFor}`، `stylesBind: {...prop_labelStyle, color: prop_labelColor}`، `classBind: [prop_labelClass]`، فرزند `<b>` با `stylesBind.fontSize = computed(sizeName → Css_FontSize(sizeName))` و children `prop_labelTitle` |
| `renderLabelTooltip()` | BORDER_CONTENT_TOOLTIP | **رندر شرطی** `conditionWhen(prop_labelTooltipDescription != null)` → wrapper `span` (position از prop) با آیکون (`UiIcons.CreateIcon(definition)`) + popup CSS-only (`:hover`) با background/color از props و `direction` کلاس top/bottom |

## ۶. ریسک‌ها و نکات

| ریسک | Mitigation |
|:---|:---|
| امضای `Simples.Border` با نام propهای موردنیاز فرق دارد (مثلاً `prop_borderRadius` ممکن است `prop_radius` باشد) | فاز ۰ بررسی ۱ — قبل از فاز ۸ قطعی شود |
| آیکون `exclamation_square` در `UiIcons.Src` نیست | نزدیک‌ترین آیکون موجود؛ در صورت لزوم ثبت definition جدید در ui_icons |
| popup CSS-only و RTL | popup با `inset-inline-start` (logical property) — نه left/right خام |
| `for` بدون input مرتبط بی‌اثر است | مثال Default شامل input نمونه با id مطابق `prop_labelFor` |
| تداخل نام کلید زبان | بخش `components.label` جدید است — بررسی عدم وجود قبل از درج |
