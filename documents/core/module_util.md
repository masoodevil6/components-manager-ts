# ماژول Util (ابزارهای کمکی)

این ماژول شامل مجموعه‌ای از ابزارهای کمکی (Utilities) است که در تمام لایه‌های سیستم (Core, UI, etc.) برای تسهیل عملیات‌های فنی، پردازش داده‌ها و مدیریت ساختارها استفاده می‌شوند. این ماژول با هدف داشتن وابستگی صفر به سایر بخش‌های اصلی طراحی شده است.

## 🚀 دسترسی عمومی (Public API)
این بخش شامل مقادیر اکسپوز شده در `public.ts` مربوط به ماژول `util` است:

### `Utils` / `Helpers`
مجموعه‌ای از توابع و کلاس‌های کمکی برای عملیات‌های رایج.

| متد/ابزار | توضیحات |
| :--- | :--- |
| `DOM Helpers` | ابزارهای مدیریت سریع‌تر DOM بدون استفاده از متدهای سنگین مرورگر. |
| `Data Formatters` | تبدیل و فرمت کردن داده‌ها برای نمایش در لایه UI. |
| `Validation Tools` | ابزارهای بررسی صحت داده‌ها (Validators) در سطح هسته. |
| `Style Helpers` | مدیریت هوشمند کلاس‌ها و استایل‌های CSS در زمان اجرا. |

## 🛠 ساختار داخلی (Internal Architecture)

* **Zero-Dependency:** این ماژول هیچ وابستگی به `core` یا `ui` ندارد تا از حلقه‌های وابستگی (Circular Dependencies) جلوگیری شود.
* **Functional Approach:** اکثر ابزارها به صورت توابع خالص (Pure Functions) پیاده‌سازی شده‌اند تا تست‌پذیری آن‌ها حداکثری باشد.
* **Performance Optimized:** برای عملیات‌های پرکاربرد (مانند پردازش آرایه‌ها یا رشته‌ها)، از الگوریتم‌های بهینه‌شده استفاده شده است.
