# ماژول Excel (ابزارهای کار با اکسل)

این ماژول شامل ابزارهای کمکی برای تولید، خواندن یا پردازش داده‌های مربوط به فرمت Excel است. این بخش معمولاً برای گزارش‌گیری‌ها و خروجی‌های داده‌ای در پروژه‌های بزرگ استفاده می‌شود.

## 📂 ساختار زیرمجموعه‌ها
- **Methods:** شامل تمامی توابع عملیاتی برای کار با فایل‌های اکسل.

## 💡 مثال استفاده (فرضی)
```typescript
import { Excel } from "@/framework/module_util/module_excel";

// مثال تولید یک فایل اکسل از داده‌های خام
const excelFile = Excel.Methods.generateFromData(myData);
```
