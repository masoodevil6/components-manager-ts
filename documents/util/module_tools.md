# ماژول ابزارها (Tools Module)

این ماژول شامل مجموعه‌ای از توابع کمکی (Utility Functions) بسیار کاربردی و عمومی است که برای تسهیل عملیات‌های رایج در برنامه‌نویسی استفاده می‌شوند. این ابزارها به گونه‌ای طراحی شده‌اند تا کدهای تکراری را حذف کرده و کار با ساختارهای داده‌ای مختلف (مانند آرایه‌ها، اشیاء و رشته‌ها) را ساده‌تر کنند.

## 🚀 دسترسی عمومی (Public API)
شما از طریق گروه‌بندی‌های زیر به ابزارهای مورد نیاز خود دسترسی دارید:

| گروه | توضیحات | کاربرد اصلی |
| :--- | :--- | :--- |
| **`Array`** | عملیات‌های پیشرفته روی آرایه‌ها. | فیلتر کردن، تبدیل و مدیریت مجموعه‌ها. |
| **`Copy`** | ابزارهای کپی کردن داده‌ها. | ایجاد کپی‌های عمیق (Deep Copy) برای جلوگیری از تغییر در منبع اصلی. |
| **`Json`** | مدیریت عملیات‌های مربوط به فرمت JSON. | پارس کردن و کار با ساختارهای JSON. |
| **`Attrs`** | مدیریت ویژگی‌ها (Attributes). | کار با مجموعه‌ای از ویژگی‌ها در المان‌ها یا اشیاء. |
| **`Replace`** | ابزارهای جایگزینی رشته‌ها و داده‌ها. | جستجو و جایگزینی الگوهای خاص. |

## 💡 مثال‌های کاربردی (Usage Examples)

### ۱. استفاده از `Json` برای پارس کردن امن
اگر می‌خواهید یک رشته JSON را با اطمینان به شیء تبدیل کنید:

```typescript
import { Json } from "@/framework/util/module_tools";

const jsonString = '{"id": 1, "name": "Test"}';
const data = Json.GetJsonParse(jsonString);

console.log(data.name); // خروجی: "Test"
```

### ۲. استفاده از `Copy` برای کپی عمیق (Deep Copy)
برای اینکه تغییر در یک شیء جدید، شیء اصلی را خراب نکند:

```typescript
import { Copy } from "@/framework/util/module_tools";

const original = { user: { name: "Ali" }, settings: { theme: "dark" } };
const clone = Copy.deepCopy(original);

clone.user.name = "Reza";
console.log(original.user.name); // همچنان "Ali" باقی می‌ماند
```

### ۳. مدیریت ویژگی‌ها با `Attrs`
برای کار با مجموعه‌ای از ویژگی‌های یک المان:

```typescript
import { Attrs } from "@/framework/util/module_tools";

// فرض بر این است که متدی برای ترکیب یا مدیریت ویژگی‌ها وجود دارد
const combinedAttrs = Attrs.merge({ id: "main" }, { class: "active" });
```

## 🛠 ساختار داخلی (Internal Architecture)

* **Functional Approach:** تمامی توابع در این ماژول به صورت Pure Function طراحی شده‌اند؛ یعنی هیچ وابستگی به وضعیت خارجی ندارند و فقط با ورودی‌های خود کار می‌کنند.
* **Complexity Hiding:** الگوریتم‌های پیچیده (مانند پیمایش بازگشتی برای کپی عمیق یا مدیریت سلسله‌مراتبی در JSON) پشت یک API ساده پنهان شده‌اند.
* **High Performance:** بهینه‌سازی شده برای کار با حجم بالای داده‌ها، به‌خصوص در عملیات‌هایی مانند `Array` و `Json`.
