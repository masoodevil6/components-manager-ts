# ماژول Tools (ابزارهای عمومی)

این ماژول شامل مجموعه‌ای از ابزارهای کمکی (Utility Functions) بسیار کاربردی است که برای انجام عملیات‌های رایج بر روی انواع داده‌ها (آرایه، رشته، اشیاء و غیره) طراحی شده‌اند. این ابزارها باعث ساده‌تر شدن منطق برنامه‌نویسی و جلوگیری از تکرار کد (DRY principle) می‌شوند.

## 🚀 دسترسی عمومی (Public API)
بر اساس فایل `public.ts` در این ماژول، شما از طریق نام‌های زیر به متدهای اصلی دسترسی دارید:

| نام متد | توضیحات |
| :--- | :--- |
| `Array` | ابزارهای کمکی برای مدیریت و تبدیل آرایه‌ها (مانند کپی یا فیلتر کردن). |
| `Copy` | عملیات کپی کردن اشیاء یا آرایه‌ها (Shallow/Deep Copy). |
| `Json` | متدهای کار با فرمت JSON. |
| `Attrs` | تبدیل داده‌ها به ویژگی‌های (Attributes) مناسب برای المان‌های HTML. |
| `Replace` | ابزارهای جایگزینی و اصلاح رشته‌ها یا ساختارها. |

## 💡 مثال استفاده
```typescript
import { Tools } from "@/framework/module_util/module_tools";

// مثال استفاده از متد کپی آرایه
const original = [1, 2, 3];
const cloned = Tools.Copy.array(original);

// مثال استفاده از تبدیل به Attribute برای المان‌ها
const elementAttrs = Tools.Attrs.fromObject({ id: "main", role: "button" });
```

## 📂 دسته‌بندی متدها
این ماژول بر اساس نوع داده‌ای که هدف قرار می‌دهد، سازمان‌دهی شده است:
- **Methods/Array:** عملیات روی آرایه‌ها.
- **Methods/String:** عملیات روی رشته‌ها (در بخش Replace).
- **Methods/Object:** عملیات روی اشیاء (در بخش Copy و Json).
