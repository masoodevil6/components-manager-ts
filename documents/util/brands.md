# ماژول Brands

این ماژول برای مدیریت برندها و آیکون‌های مرتبط با آن‌ها استفاده می‌شود.

## 🚀 دسترسی عمومی (Public API)
بر اساس فایل `public.ts` در این ماژول، از طریق `Icons` به آیکون‌ها دسترسی دارید:

```typescript
import { Icons } from "@/framework/module_util/module_brands";
```

## 🛠 ساختار داخلی
- **Types:** شامل تعریف تایپ‌های مربوط به برندها و آیکون‌ها.
