# ماژول تاریخ (Dates Module)

این ماژول وظیفه مدیریت زمان و استخراج مقادیر زمانی خاص را بر عهده دارد. تمرکز اصلی این ماژول بر روی کار با **Unix Timestamp** است که روشی استاندارد، سبک و بدون وابستگی به منطقه زمانی (Timezone) برای ذخیره و انتقال داده‌های زمانی در سیستم‌های توزیع شده است.

## 🚀 دسترسی عمومی (Public API)
شما از طریق زیرگروه `TimeUnix` به متدهای اصلی این ماژول دسترسی دارید:

### `TimeUnix` (مدیریت زمان بر پایه Unix Timestamp)
این بخش شامل متدهایی برای دریافت لحظه‌ای زمان و زمان‌های خاص در بازه‌های زمانی مختلف است.

| متد | توضیحات |
| :--- | :--- |
| **`ThisTime`** | بازگرداندن دقیقاً زمان جاری (لحظه کنونی) به صورت Unix Timestamp. |
| **`ThisYear`** | بازگرداندن اولین لحظه از سال جاری به صورت Unix Timestamp. |

---

## 💡 مثال‌های کاربردی (Usage Examples)

### ۱. دریافت زمان جاری برای ذخیره در دیتابیس
اگر نیاز دارید زمان دقیق یک رویداد را ثبت کنید، بهترین روش استفاده از `ThisTime` است:

```typescript
import { TimeUnix } from "@/framework/util/module_dates";

// دریافت زمان کنونی به عنوان عدد (Timestamp)
const now = TimeUnix.ThisTime();

console.log(now); // خروجی مثلاً: 1715674200
```

### ۲. استفاده از زمان شروع سال برای محاسبات بازه‌های زمانی
اگر بخواهید عملیاتی را فقط برای داده‌های مربوط به سال جاری انجام دهید، می‌توانید از `ThisYear` استفاده کنید:

```typescript
import { TimeUnix } from "@/framework/util/module_dates";

// دریافت زمان شروع سال جاری
const startOfYear = TimeUnix.ThisYear();

console.log("Start of year timestamp:", startOfYear);
```

## 🛠 ساختار داخلی (Internal Architecture)

* **Timestamp Centric:** برخلاف استفاده از اشیاء سنگین `Date` در جاوااسکریپت، این ماژول بر روی اعداد صحیح (`number`) تمرکز دارد که باعث افزایش سرعت پردازش و کاهش مصرف حافظه می‌شود.
* **Atomic Operations:** هر متد یک عملیات اتمیک (Atomic) را انجام می‌دهد و وابستگی به وضعیت‌های جهانی (Global State) ندارد.
* **Stateless Design:** این ماژول بدون داشتن هیچ‌گونه حالت داخلی (State)، صرفاً به عنوان یک ابزار (Utility) عمل می‌کند که قابلیت تست‌پذیری بسیار بالایی دارد.
