# ماژول Consts (ثابت‌های سیستم)

این ماژول شامل تمام مقادیر ثابت (Constants) مورد نیاز برای کل فریم‌ورک است، از جمله رنگ‌ها، اندازه‌ها و سبک‌های پیش‌فرض. استفاده از این ماژول باعث یکپارچگی در ظاهر (Consistency) پروژه می‌شود.

## 📂 ساختار زیرمجموعه‌ها
- **Colors:** شامل پالت‌های رنگی اصلی (`CsColorMain`) و گرادیانت‌ها.
- **Files:** ثابت‌های مربوط به نام فایل‌ها یا مسیرهای خاص.
- **Sizes:** اندازه‌های استاندارد (مانند پیکسل‌ها برای پدینگ، مارجین و غیره).
- **Styles:** مقادیر ثابت مربوط به استایل‌های CSS.

## 💡 مثال استفاده
```typescript
import { Colors } from "@/framework/module_util/module_consts";

const primaryColor = Colors.Colors.CsColorMain.primary;
```
