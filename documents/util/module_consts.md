# ماژول ثوابت (Constants Module)

این ماژول شامل مجموعه‌ای از مقادیر ثابت، انواع داده‌ای پایه و تعاریف استاتیک است که در سراسر سیستم برای حفظ یکپارچگی استفاده می‌شوند. این ماژول به جای داشتن منطق اجرایی، بر روی **Single Source of Truth** تمرکز دارد تا تغییر در یک نقطه، تمام اجزای وابسته را با دقت به‌روز کند.

## 🚀 دسترسی عمومی (Public API)
شما از طریق گروه‌بندی‌های زیر به مقادیر ثابت دسترسی دارید:

### ۱. اندازه‌ها و واحدها (`Sizes` & `Units`)
این بخش برای مدیریت دقیق ابعاد در لایه UI استفاده می‌شود:

| گروه | توضیحات | مثال‌ها |
| :--- | :--- | :--- |
| **`Sizes`** | تعریف مقادیر استاندارد اندازه (از کوچک به بزرگ) | `XS`, `S`, `M`, `L`, `XL`, `XXL` |
| **`Units`** | واحدهای اندازه‌گیری برای استایل‌ها | `%` (Percent), `px` (Pixel), `pt` (Point) |

### ۲. رنگ‌ها (`Colors`)
مدیریت طیف‌های رنگی و سیستم‌های رنگی:
* **`ColorMain`**: رنگ‌های اصلی برند یا سیستم.
* **`ColorGrad`**: مجموعه‌ای از گرادیانت‌ها یا طیف‌های رنگی پیش‌فرض.

### ۳. استایل‌ها و لایه‌بندی (`Styles`)
ثوابت مربوط به ویژگی‌های بصری:
* **`ZIndex`**: مدیریت اولویت نمایش عناصر در لایه‌های مختلف (Stacking Context).

### ۴. فایل‌ها (`Files`)
تعاریف استاندارد برای کار با سیستم فایل:
* **`FileMimeTypes`**: لیست انواع MIME برای شناسایی فرمت‌ها.
* **`FileExtensionTypes`**: لیست پسوندهای استاندارد فایل‌ها.

## 💡 مثال‌های کاربردی (Usage Examples)

### ۱. استفاده از اندازه‌ها در استایل‌دهی
```typescript
import { Sizes, Units } from "@/framework/util/module_consts";

// تعریف یک مقدار استاندارد برای سایز یک المان
const elementSize = `${Sizes.M}${Units.PEXEL}`; // "Mediumpx" (بسته به پیاده سازی Enum)
```

### ۲. مدیریت لایه‌بندی با ZIndex
```typescript
import { ZIndex } from "@/framework/util/module_consts";

// استفاده از مقادیر ثابت برای جلوگیری از تداخل لایه‌ها
const modalZIndex = ZIndex.MODAL; 
const tooltipZIndex = ZIndex.TOOLTIP;
```

## 🛠 ساختار داخلی (Internal Architecture)

* **Zero-Logic Approach:** این ماژول تنها شامل `enum`ها و `const`های ساده است تا از پیچیدگی‌های اجرایی جلوگیری شود.
* **Type Safety:** با استفاده از `enum` در TypeScript، تضمین می‌شود که توسعه‌دهنده فقط از مقادیر مجاز (مانند `Sizes.XS`) استفاده می‌کند و از ورود رشته‌های اشتباه جلوگیری می‌شود.
* **Centralized Configuration:** تمام مقادیر بصری پایه (مثل رنگ‌ها یا اندازه‌ها) در اینجا متمرکز شده‌اند تا تغییر سبک ظاهری سیستم (Theming) با کمترین تلاش ممکن انجام شود.
