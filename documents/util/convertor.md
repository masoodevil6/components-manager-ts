# ماژول Convertor (تبدیل انواع داده)

این ماژول شامل ابزارهای قدرتمند برای تبدیل انواع مختلف داده‌ها به یکدیگر است. این تبدیل‌ها به صورت تمیز و با استفاده از متدهای اختصاصی پیاده‌سازی شده‌اند تا از بروز خطاهای تایپی جلوگیری شود.

## 🚀 دسترسی عمومی (Public API)
بر اساس فایل `public.ts` در این ماژول، شما از طریق نام‌های زیر به متدها دسترسی دارید:

| نام متد | توضیحات |
| :--- | :--- |
| `Array` | ابزارهای تبدیل و مدیریت آرایه‌ها |
| `Copy` | عملیات کپی کردن اشیاء و آرایه‌ها (Deep/Shallow) |
| `Json` | تبدیل‌های مرتبط با فرمت JSON |
| `Attrs` | تبدیل مقادیر به ویژگی‌ها (Attributes) برای المان‌ها |
| `Replace` | ابزارهای جایگزینی در رشته‌ها یا ساختارها |

## 💡 مثال استفاده
```typescript
import { Convertor } from "@/framework/module_util/module_convertor";

// مثال تبدیل یک آرایه به فرمت خاص
const result = Convertor.Array.someMethod(myArray);

// مثال کار با JSON
const jsonString = Convertor.Json.stringify(myData);
```

## 📂 دسته‌بندی متدها
این ماژول بر اساس نوع داده تقسیم‌بندی شده است:
- **Number:** تبدیل‌های مربوط به اعداد و مقادیر ریاضی.
- **String:** عملیات رشته‌ای پیشرفته.
- **Object:** مدیریت و تبدیل ساختارهای شیء‌گرا.
- **Price:** ابزارهای تخصصی برای فرمت‌دهی قیمت‌ها.
