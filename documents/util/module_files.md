# ماژول فایل‌ها (Files Module)

این ماژول مجموعه‌ای از ابزارهای کمکی برای کار با نام فایل‌ها، پسوندها و انواع MIME فراهم می‌کند. هدف این ماژول، ساده‌سازی عملیات‌های مربوط به شناسایی نوع فایل و مدیریت رشته‌های مربوط به نام فایل در محیط‌های مختلف است.

## 🚀 دسترسی عمومی (Public API)
شما از طریق توابع زیر به قابلیت‌های این ماژول دسترسی دارید:

| متد | توضیحات |
| :--- | :--- |
| **`GetExtension`** | استخراج پسوند فایل از یک رشته نام فایل. |
| **`GetIMimeType`** | دریافت نوع MIME (MIME Type) بر اساس نام یا پسوند فایل. |
| **`GetInfo`** | دریافت اطلاعات جامع‌تر مربوط به یک فایل (مانند حجم، نام و ...). |

---

## 💡 مثال‌های کاربرادی (Usage Examples)

### ۱. استخراج پسوند فایل (Extension)
اگر می‌خواهید بدانید یک فایل از چه نوعی است (مثلاً `.pdf` یا `.png`)، از `GetExtension` استفاده کنید:

```typescript
import { GetExtension } from "@/framework/util/module_files";

const fileName = "report_2023.pdf";
const extension = GetExtension(fileName);

console.log(extension); // خروجی: "pdf"
```

### ۲. شناسایی نوع فایل (MIME Type)
برای بررسی اینکه آیا یک فایل قابل آپلود است یا خیر، از `GetIMimeType` استفاده می‌شود:

```typescript
import { GetIMimeType } from "@/framework/util/module_files";

const mime = GetIMimeType("image.png");

console.log(mime); // خروجی مثلاً: "image/png"
```

## 🛠 ساختار داخلی (Internal Architecture)

* **String-Based Processing:** تمام عملیات‌ها بر پایه پردازش رشته‌های نام فایل انجام می‌شود که بسیار سریع و بدون نیاز به دسترسی به سیستم فایل واقعی است.
* **Robustness:** الگوریتم‌های استفاده شده در این ماژول برای مدیریت حالت‌های خاص (مانند فایل‌های بدون پسوند یا نام‌های غیرمعتبر) بهینه شده‌اند تا از خطاهای Runtime جلوگیری شود.
* **Utility-First Design:** این ماژول با هدف قرار دادن وظایف کوچک و تکراری طراحی شده تا توسعه‌دهندگان بتوانند بدون نوشتن کدهای پیچیده، مدیریت فایل‌ها را انجام دهند.
