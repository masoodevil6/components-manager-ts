# ماژول Files (مدیریت فایل‌ها)

این ماژول شامل ابزارهای کمکی برای مدیریت، خواندن و کار با ساختار فایل‌ها در سیستم است. این بخش برای عملیات مربوط به آپلود، دانلود یا بررسی وجود فایل‌ها کاربرد دارد.

## 📂 ساختار زیرمجموعه‌ها
- **Methods:** شامل توابع مربوط به عملیات روی فایل (مانند چک کردن پسوند یا حجم فایل).
- **Types:** انواع داده‌ای تعریف شده برای مدل‌های فایل.

## 💡 مثال استفاده
```typescript
import { Files } from "@/framework/module_util/module_files";

// بررسی معتبر بودن یک فرمت فایل
const isValid = Files.Methods.checkExtension(myFile, ".pdf");
```
