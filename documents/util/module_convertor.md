# ماژول تبدیلگر (Convertor Module)

این ماژول شامل مجموعه‌ای از توابع تبدیل (Transformation Functions) است که وظیفه تغییر فرمت، تبدیل نوع داده یا ترجمه مقادیر را در سطح سیستم بر عهده دارند. این ماژول برای ساده‌سازی عملیات‌های رایج مانند تبدیل اعداد به زبان‌های مختلف یا مدیریت انواع داده‌ای پیچیده طراحی شده است.

## 🚀 دسترسی عمومی (Public API)
شما از طریق گروه‌بندی‌های زیر به متدهای تبدیل دسترسی دارید:

| گروه | توضیحات |
| :--- | :--- |
| **`Number`** | تبدیل‌ها و عملیات‌های مربوط به اعداد (مانند ترجمه اعداد انگلیسی به فارسی). |
| **`String`** | عملیات‌های تغییر فرمت رشته‌ها و پردازش متن. |
| **`Array`** | تبدیل‌ها و عملیات‌های ساختاری روی آرایه‌ها. |
| **`Object`** | مدیریت و تبدیل انواع داده‌های شیء‌ساز (Object-based). |
| **`Price`** | تبدیل‌های خاص مربوط به فرمت‌های قیمت و پول. |

## 💡 مثال‌های کاربردی (Usage Examples)

### ۱. ترجمه اعداد (از انگلیسی به فارسی)
یکی از کاربردهای اصلی در گروه `Number` برای نمایش صحیح اعداد در محیط‌های فارسی است:

```typescript
import { Number } from "@/framework/util/module_convertor";

const englishNumber = "12345";
const persianNumber = Number.FromEnglishToPersian(englishNumber); 

console.log(persianNumber); // خروجی: ۱۲۳۴۵
```

### ۲. مدیریت قیمت‌ها (Price Conversion)
برای تبدیل فرمت‌های مختلف قیمت به یک استاندارد واحد:

```typescript
import { Price } from "@/framework/util/module_convertor";

const rawPrice = 10000;
// فرض بر این است که متد مربوطه در زیرگروه price تعریف شده است
const formattedPrice = Price.format(rawPrice, "IRT"); 
```

## 🛠 ساختار داخلی (Internal Architecture)

* **Specialized Transformers:** هر گروه از تبدیل‌ها (مانند `Number` یا `String`) دارای منطق اختصاصی خود است تا از سنگین شدن یک تابع واحد جلوگیری شود.
* **High-Level Abstraction:** این ماژول از لایه پایین‌تر (`Core`) استفاده می‌کند تا مطمştir شود که عملیات‌های تبدیل، با قوانین اصلی سیستم (مانمانند مدیریت انواع داده) سازگاری دارند.
* **Extensibility:** ساختار `methods/` به گونه‌ای طراحی شده که اضافه کردن گروه‌های جدید (مثلاً برای تبدیل‌های زمانی یا جغرافیایی) بدون تغییر در هسته ماژول امکان‌پذیر است.
