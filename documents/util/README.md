# مستندات ماژول‌های ابزار (Utility Modules)

این پوشه شامل مستندات مربوط به ماژول‌های کمکی (`util`) در فریم‌ورک است. هر فایل `.md` توضیحات، متدها و مثال‌های استفاده از یک ماژول خاص را ارائه می‌دهد.

## لیست ماژول‌ها
- [Brands](./brands.md) - مدیریت برندها و آیکون‌های مرتبط
- [Consts](./consts.md) - ثابت‌های سیستم (رنگ‌ها، اندازه‌ها و غیره)
- [Convertor](./convertor.md) - ابزارهای تبدیل انواع داده
- [Dates](./dates.md) - مدیریت تاریخ و زمان
- [Excel](./excel.md) - ابزارهای کار با اکسل
- [Files](./files.md) - مدیریت فایل‌ها
- [Styles](./styles.md) - مدیریت استایل‌ها و کلاس‌های CSS
- [Tools](./tools.md) - ابزارهای عمومی (آرایه، رشته، اشیاء و غیره)
- [Validators](./validators.md) - اعتبارسنجی داده‌ها
