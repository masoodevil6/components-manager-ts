# ماژول Dates (مدیریت تاریخ و زمان)

این ماژول شامل ابزارهای کمکی برای کار با انواع داده‌های زمانی، تبدیل فرمت‌ها و مدیریت مقادیر Unix Timestamp است. هدف این ماژول ساده‌سازی عملیات پیچیده مربوط به تاریخ در پروژه‌های بزرگ است.

## 📂 ساختار زیرمجموعه‌ها
- **Methods:** شامل تمام متدهای کاربردی برای پردازش تاریخ.

## 💡 مثال استفاده
```typescript
import { Dates } from "@/framework/module_util/module_dates";

// تبدیل یک Timestamp به فرمت خوانا یا مدیریت زمان‌های مختلف
const formattedDate = Dates.Methods.someMethod(unixTimestamp);
```

## 🛠 قابلیت‌ها
- تبدیل خودکار `Unix Timestamp` به اشیاء تاریخ استاندارد.
- متدهای کمکی برای مقایسه و محاسبات زمانی سریع.
