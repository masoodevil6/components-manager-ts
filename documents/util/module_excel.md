# ماژول اکسل (Excel Module)

این ماژول وظیفه آماده‌سازی داده‌ها برای خروجی گرفتن در قالب فایل‌های اکسل را بر عهده دارد. تمرکز اصلی این ماژول بر روی اضافه کردن شناسه‌های ستونی استاندارد (مانند A, B, C, ...) به مجموعه‌ای از داده‌ها است تا فرآیند تولید فایل اکسل بدون خطا و با ترتیب صحیح انجام شود.

## 🚀 دسترسی عمومی (Public API)
شما از طریق تابع زیر به قابلیت‌های این ماژول دسترسی دارید:

### `AddExcelKeys` (افزودن کلیدهای ستونی اکسل)
این تابع یک لیست از اشیاء را می‌گیرد و به هر شیء، یک کلید جدید (به صورت پیش‌فرض `excelKey`) اضافه می‌کند که شامل نام ستونی استاندارد اکسل است.

| پارامتر | نوع | توضیحات |
| :--- | :--- | :--- |
| `list` | `T[]` | آرایه‌ای از اشیاء که قرار است پردازش شوند. |
| `keyName` | `string` (اختیاری) | نام کلیدی که قرار است به اشیاء اضافه شود (پیش‌فرض: `"excelKey"`). |

## 💡 مثال‌های کاربردی (Usage Examples)

### ۱. آماده‌سازی داده‌ها برای خروجی اکسل
اگر مجموعه‌ای از داده‌ها (مثلاً لیست کاربران) را دارید، ابتدا باید آن‌ها را از این تابع عبور دهید تا هر ردیف یک ستون مشخص داشته باشد:

```typescript
import { AddExcelKeys } from "@/framework/util/module_excel";

interface User {
    id: number;
    name: string;
}

const users: User[] = [
    { id: 1, name: "Ali" },
    { id: 2, name: "Reza" }
];

// اضافه کردن کلید ستونی برای اکسل
const dataForExcel = AddExcelKeys(users, "column_id");

console.log(dataForExcel);
/*
خروجی مشابه:
[
  { id: 1, name: "Ali", column_id: "A" },
  { id: 2, name: "Reza", column_id: "B" }
]
*/
```

## 🛠 ساختار داخلی (Internal Architecture)

* **Column Mapping Logic:** این ماژول از یک الگوریتم ریاضی برای تبدیل ایندکس عددی به نام‌های استاندارد اکسل (مانند `A`, `B`, ..., `AA`, `AB`) استفاده می‌کند.
* **Immutability:** تابع با استفاده از `map` و Spread Operator، یک نسخه جدید از آرایه را برمی‌گرداند و به داده‌های اصلی آسیب نمی‌زند.
* **Generic Support:** با استفاده از Genericهای TypeScript، این ماژول می‌تواند با هر نوع شیئی (Object) کار کند و در عین حال تایپ‌سیفتی (Type Safety) را حفظ کند.
